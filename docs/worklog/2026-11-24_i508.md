# 2026-11-24 — #508 레이스 시작 설정 (랩·봇 수·차·색이 레이스 씬까지)

- 스펙 #505, ADR-562. `RaceEvent.Chosen`(코스 Id 문자열) → `RaceEvent.Starting`(`RaceStart`: 코스, 랩, 봇 수, 사람별 `{세션 토큰 | 로컬, 차 모델, 색}`)으로 교체.
- `RaceStart` 기본값: 랩 0 = 코스의 랩, 봇 -1 = 오늘처럼 8대(`RaceEvent.Racers`)까지 채움, 항목 없음 = 슬롯 차. 설정이 없거나 다른 씬의 코스면 오늘 그대로.
- 순수 규칙(`RaceEvent`): `LapsOf`(스프린트 = 열린 코스는 1회 고정), `FieldSize`(사람 + 봇, 그리드 12 상한), `EntryFor`(토큰 없는 항목 = 호스트 본인, 아니면 세션 토큰으로).
- `RaceDirector`: `Laps` 속성이 `Info.Laps` 대신 `LapsFor`(부정 출발 +1 랩 포함)와 `RaceStandings.Laps`에 쓰임. `FillWithBots`는 `FieldSize`까지. `SpawnCar(slot, entry)`는 항목의 모델(`Vehicle.ModelName`)·색(유효 범위만)을 쓰고, 없거나 씬에 없는 모델이면 오늘의 슬롯 차·색. 사람 토큰은 `MatchDirector.Sessions.TokenOf` — 전용 서버 연결(#511/#513)이 그대로 쓰면 됨. 봇 실력 분포는 `field - 1` 기준(설정 없으면 7 = 오늘과 같음).
- `MainMenu.StartEvent(course, laps, bots, car, paint)`: 솔로 경로가 로컬 선택으로 설정을 만듦(기본 인자 = 오늘 동작). 로비 시작 경로(`LobbyStart.Event`)도 `RaceStart { CourseId }`로 바뀜(랩·봇은 #511/#513).
- 테스트: `RaceStartTests`(EditMode 4개), `RaceStartPlayTests.Solo_ThreeLaps_FourBots_Shvan92InPaint2`(메뉴 → StartEvent → 5대, 내 차 Shvan92 색 2, 2랩 후 미완주, 3랩 후 완주). `PassCoursePlayTests`는 `Chosen` 대신 `Starting` 설정으로만 바꿈. 회귀: `RaceEventTests`, `RaceEventPlayTests`, `RaceEventMenuTests`, `RaceEventMultiTests`, `PassCoursePlayTests`.
- 범위 밖: 방(#507 RaceLobby)·차고 선택 UI가 아직 없어 메뉴의 이벤트 화면은 기본 인자로 호출(오늘과 같음). 서버의 범위 검증은 프로토콜 티켓 몫.
- 결과: EditMode 11/11, PlayMode 16/17 통과(새 솔로 3랩 테스트 194 s 통과). 실패 1개 `PassCoursePlayTests.Pass_RendersWithinBudget`(렌더 p99 10.2 ms, 재실행 14.3 ms, 예산 10 ms)는 다른 Unity가 동시에 돌 때 잰 렌더 성능 — 이 변경은 고개 코스의 차 수·렌더를 바꾸지 않음(설정에 봇 미지정 = 8대 그대로). 독점 창 재측정 필요.
