# 2026-11-24 #510 레이스 HUD: 선두와의 차이·앞 차와의 차이·미니맵 (ADR-562)

## 바뀐 것
- **`RaceSplits`**(Core/RaceLap.cs): 서버가 차마다 진행 거리(RaceLap.Progress) 25 m 지점을 지난 레이스 시간을 적는다. `Gaps` = 같은 지점에서 선두와의 시간 차(선두 0, 아직 모름 -1), 완주한 차는 완주 시간 차. 순서는 지금 위치, 지점 기록은 최대 25 m 전이라 순서와 어긋날 수 있어 **앞 차보다 작지 않게** 고정(앞 차와의 차이가 음수가 되지 않음).
- **`RaceDirector`**: Judge에서 매 프레임 기록, `RaceStandings.Gaps`(float[]) 추가해 보냄.
- **`RaceHudView`**: 레이스 중 화면을 목업(race_room.html, 1280 좌표 x1.5) 배치로 바꿈.
  - 왼쪽 위: 순위 `5/8`·랩 `1/2` 패널(스프린트는 "남은 거리"에 남은 m·%, 부정 출발은 "랩 (부정 출발 +1)").
  - 그 아래: 순위표(순위·이름·+gap, 내 행 파란 바탕, 선두는 빈칸, 완주 표시). 옛 오른쪽 순위 글자 목록은 없앰(미니맵 자리).
  - 위 가운데: 랩 시계 + 그 아래 노란 "앞 차와 +0.337"(1위면 "선두", 완주면 "완주!", 마감 중이면 "종료까지 n초" 한 줄 더).
  - 오른쪽 위: 코스 미니맵(목업 trackSVG처럼 어두운 넓은 선 + 흰 가는 선, 갈림길 포함, 북쪽 위, 한 번만 텍스처로 그림) + 모든 차 점(내 차 큰 주황, 맨 위).
  - 왼쪽 아래: 베스트 랩(스프린트에선 숨김).
  - 글자는 서버 소식(초당 4회)이 올 때만 다시 만들고, 매 프레임은 랩 시계와 점 위치만.
- **캡처**: `RaceHudCaptureTests`(PlayMode, Explicit, Capture): 스네이크 2랩·봇 7, 내 차를 4초 늦게 출발시켜 봇 운전 로직으로 22초 주행 후 1920x1080·1728x1080을 카메라→텍스처로 찍음(창 없음). GoblinV12(계기판 C)·FairheavenLT80(계기판 D).
  `RACE_HUD_SHOTS=Logs/race_hud tools/unity.sh test playmode Game.Tests.RaceHudCaptureTests`
- **main 컴파일 오류 수정**: `RaceBalancePlayTests`가 #508에서 사라진 `RaceEvent.Chosen`을 써서 PlayMode 어셈블리가 안 됐음 → `RaceEvent.Starting = new RaceStart { CourseId = id }`.

## 확인
- EditMode `RaceGapTests` 4개(선두 0·같은 지점 차이, 완주는 완주 시간·출발 전 -1, 지점 건너뛰기·음수 없음, 앞 차보다 작지 않음) + RaceStartTests 등 15/15 통과.
- PlayMode `RaceHudCaptureTests` 2/2 통과(Gaps 길이 = 순위 수, 선두 0, 22초 뒤 전원 gap 앎, 내 앞에 차 있음).
- 캡처 판정(엄격): 1차 — LT80 모델명 오류(`FairheavenLT80`), 내가 1위라 "앞 차와" 줄이 안 보임, 베스트 랩 "-:--.--"가 깨져 보임. 2차 — 순위표 gap이 순서와 어긋남(3위 +1.107 > 4위 +1.031). 모두 고친 3차: 목업 배치와 일치, 계기판 C/D·16:10과 겹침 없음, 표와 앞 차 줄 값 일치(1.886−1.549=0.337).

## 목업과 남은 차이 (가정)
- 랩 시계 형식은 이슈대로 기존 `RaceBoard.Time`("23.15", 1분 넘으면 "1:05.30") 유지 — 목업은 "0:00.000".
- 목업은 계기판을 아래 가운데 한 덩어리로 그렸지만 ADR-563 배치(타코 왼쪽·속도계 오른쪽)를 따름.
- 캡처는 카메라를 거쳐 비네트가 걸려 왼쪽 아래 베스트 랩 패널이 실제보다 어둡게 나옴(실게임 오버레이는 영향 없음).
- 출발 직후라 차들이 몰려 미니맵 점이 겹쳐 보임.
