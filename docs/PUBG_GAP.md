- 경로 약어: `S/` = `Assets/_Project/Scripts/`, `E/` = `Assets/_Project/Editor/`, `D/` = `Assets/_Project/Data/Resources/GameData/`.
- 우선순위: **P0** = M4 전 반드시 / **P1** = M4까지 하면 좋음 / **P2** = M5 이후. 난이도: S(반나절 이하) · M(에이전트 1명 1회) · L(여러 회).
