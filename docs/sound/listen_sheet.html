사운드 청취 시트

각 소리를 듣고 좋음 / 교체 / 다시 자르기를 고르면 브라우저에 저장됩니다. 맨 아래 "결과 복사"를 눌러 채팅에 붙여넣어 주세요. 저장소 루트에서 python3 -m http.server 후 /docs/sound/listen_sheet.html로 열거나 파일로 열기(상대 경로).

특히 들어볼 곳

  • 소총(rifle): 원본이 클리핑된 연발 녹음의 마지막 발입니다. 거칠면 교체(다운로드 요청 목록 참고).
  • SMG near: 연발에서 한 발 주기(약 70ms)만 잘랐습니다. "딱" 소리만 나면 다시 자르기.
  • DMR: 2차대전 카빈 단발입니다(현대 소총과 다름).
  • far 파일은 저역 통과+지연으로 만든 먼 소리, 실제 게임에서는 거리 30~200m 구간에서 섞입니다.
