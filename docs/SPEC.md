# SPEC — 게임 기획서 (GDD) · 단일 진실 원천

## 1. 컨셉
거대한 폐쇄 시설(오리지널 세계관, 메이즈러너에서 영감만) 안에 엘리베이터로 투입된 참가자들이 구역을 옮겨 다니며 파밍·교전하고, 구역이 **순차 봉쇄**되는 압박 속에서 최후의 개인/팀이 되는 배틀로얄. 재미 핵심: 엄폐·지형 활용 교전, 수류탄/총기, 팀플레이, 봉쇄 탈출 긴장감.
- 금지: 움직이는 미로 벽(유저 피로), 봉쇄 즉사(→ 데미지 방식).
- 고유 명칭(게임명, 세계관 용어)은 오리지널. 실존 작품 고유명사 사용 금지. 게임명은 미정.

## 2. 모드
- 솔로 / 팀(소규모). 인원수는 미결정(RISKS 참조) → MVP는 싱글플레이 + 봇.
- 싱글은 **서버 권위 구조**로 만든다(호스트 = 서버+클라이언트, 봇 = 서버측 AI) → 멀티 전환 비용 최소화.

## 3. 구역(존) 상태 머신
`safe → warning → lockdown → red-zone 폭격 → closed`
- **warning**: 예고(경고음/UI, 출구 1단계 힌트: 대략 반경).
- **lockdown**: 건물 출입 봉쇄, **방사능 지속 데미지**(즉사 아님). 탈출 수단: ① 열쇠(랜덤 스폰, 구역별 최소 개수 보장, 열린 문은 10초간 유지) ② 봉쇄 구역당 **정확히 1개의 출구**(매 판 랜덤, 2단계 힌트: 경고 때 대략 반경, 가까워지면 비콘/사이렌).
- **red-zone**: 구역 단위 미사일 폭격.
- **closed**: 진입 불가.
- 폐쇄 순서와 **최종 결전 구역은 매 판 랜덤**(중앙 코어도 일반 구역 중 하나, 항상 최종이 되면 안 됨).

### 3-1. 최종 구역 정보 공개 (배그식)
- 최종 구역은 **서버가 매치 시작 시 결정**하고 처음엔 숨긴다. 폐쇄 순서는 최종 구역을 제외하고 랜덤.
- 초반: 닫히는 구역만 순서대로 경고(최종 구역은 모름). 중반: 남은 구역이 줄며 후보가 자연스럽게 좁혀짐. 마지막 2~3개: 남은 구역이 곧 최종 후보.
- 최종 구역 내부: 수렴 지점 후보(광장, 옥상, 중앙 홀 등) 3~4곳 중 하나를 랜덤 선택하고, 구역 내부를 **소구역 단위로 순차 폭격**해 좁힌다. 모든 구역 공통 모듈(배그의 자기장 원 역할)로 한 번만 만든다.
- MVP(구역 2개)에서는 최종 구역이 2택 중 하나. 소구역 봉쇄 모듈을 처음부터 공통으로 만든다.

### 3-2. 구역별 최종전 균형
| 최종 구역 | 문제 | 완화 |
|---|---|---|
| 산악 | 저격 과다 유리 | 마지막 단계에 안개/연막 이벤트로 시야 제한 |
| 지하 / 공장 | 너무 좁아 몰림 | 수렴 지점 후보를 넓은 홀 위주로 배치 |
| 온실 | 시야 차단으로 지루함 | 마지막 단계에 식물 제거 이벤트 |

### 3-3. 구역 연결 보장
폐쇄 순서가 랜덤이어도 남은 구역끼리는 항상 엘리베이터로 연결되어야 한다 → 엘리베이터는 **허브형**(모든 구역이 서로 연결). 테스트: 임의 시드·임의 폐쇄 순서에서 남은 구역의 연결성이 항상 유지됨.

## 5. 엘리베이터 / 이동
- 구역당 3~4대. 용도: 최초 투입 + 구역 간 이동.
- 투입 후 스폰 보호 5~10초. 구역별 시작 인원 상한(한 구역에 타 팀 동시 시작 가능).
- 구역 간 이동 중에는 최대 2개 구역이 활성(성능 예산 근거).
- 차량/보트/ATV는 **후순위**(M5 이후). 차량은 오리지널 디자인 또는 CC0 에셋, 실존 브랜드/국산차 명칭·로고 사용 금지.

## 6. 사망 / 부활 (칩)
- 팀 모드 한정 **칩 부활**: 사망 시 칩 드롭, 팀원이 수거해 부활 장소에서 부활.
- 모든 구역 입구에 **칩 보관함**. 사망 후 90초까지 수거 가능. 구역 폐쇄 시 칩 파괴.
- 솔로에는 부활 없음.

## 7. 시점 / 카메라
- 배틀그라운드와 동일: TPP/FPP 전환, 카메라는 교체 가능한 컴포넌트, 카메라 충돌, 실내 처리(벽 관통 방지, 근접 시 FPP 권장).
- 에임/반동/확산, 어깨 스왑, 엄폐 기반 교전.

## 9. 아트 방향
- 성인(20~40대)이 해도 유치하지 않은 **세미리얼**. 극사실 아님(고사양 요구 회피), 카툰/로우폴리 장난감 느낌 아님.
- PBR 텍스처(ambientCG/Poly Haven CC0) + 중간 폴리 모델 + 낮은 해상도 텍스처(1K~2K KTX2) + 포스트프로세싱 절제.

## 10. 오디오 방향
- 현실적이고 묵직한 총성/환경음, 구역별 앰비언스, 봉쇄 경고 사이렌·비콘이 게임플레이 단서. 상세: AUDIO.md.
