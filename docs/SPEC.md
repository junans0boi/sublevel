# SPEC — 게임 기획서 (GDD) · 단일 진실 원천

> 개정 2026-11-16: 오염 시스템·열쇠 엘리베이터·팀 모드·50인·새 맵(C2)·총기 구성·Humanoid 전환 반영(ADR-168~176).
> 이 문서는 **개요와 규칙의 뼈대**다. 항목별 상세 수치·목록(총기, 차량, 마을, 도로 등)은 `docs/bible/`(웹: `docs/bible/index.html`, 데이터: `docs/bible/data/*.json`)이 단일 출처이며, 충돌하면 이 SPEC이 이기고 정의서를 고친다(CLAUDE.md 규칙 5).
> 수치 중 `[제안]`은 아직 플레이테스트/측정으로 조정될 값, 표시 없는 것은 준환이 확정했거나 구현돼 있는 사실이다.

## 1. 컨셉
거대한 폐쇄 시설(오리지널 세계관, 메이즈러너에서 영감만)을 모티브로 한 섬에서, **엘리베이터로 지역에 투입**된 참가자들이 파밍·교전하고, 방사능 **오염이 지역을 하나씩 삼키며 도심으로 수렴**하는 압박 속에서 최후의 개인/팀이 되는 배틀로얄. 재미 핵심: 시가전·산악전에서 엄폐·지형 활용 교전, 수류탄/총기, 팀플레이, 열쇠 엘리베이터로 오염을 피하는 탈출 긴장감.
- 분위기: 배틀그라운드급 몰입(극사실 아님). 한국 1980년대 + 열대 혼합의 가상 세계(실존 지명·상표 사용 금지).
- 금지: 움직이는 미로 벽(유저 피로), 오염 즉사(→ 지속 데미지 방식).
- 고유 명칭(게임명, 세계관 용어)은 오리지널. 실존 작품 고유명사 사용 금지. 게임명은 미정.

## 2. 모드 / 인원
- **솔로 / 스쿼드(4)**. 듀오는 지원하지 않는다(ADR-171).
- **판당 50명(사람 + 봇)**. 사람이 적으면 봇으로 채우고 많으면 봇을 줄인다(최소 봇 수 보장). 현재 구현은 최대 16명 — 확장이 필요하다(ADR-168).
- **서버 권위 구조**(ADR-003): 호스트/전용 서버 권위, 봇은 서버 측 AI, 싱글은 호스트 = 서버+클라이언트.
- 판 길이 목표 20~25분.

## 3. 오염 시스템 (구역 상태 머신 대체, ADR-169)
섬은 **6개 지역**(§4)으로 나뉜다. 지역 상태: `safe → warning → contaminated(확정) → 전선 통과 → 위험지대`.
- **순서**: 6개 지역 중 5개가 순서대로 오염 확정되고 **마지막 하나가 최종 지역**이다. 최종 지역은 서버가 시작 시 시드로 결정하며 6개 중 무작위, 남은 지역끼리는 항상 육로로 이어지는 순서만 허용한다(서남 포구처럼 막다른 지역은 이웃보다 먼저 닫힘).
- **시간표**: 확정 시각 4 / 7.5 / 10.5 / 13 / 15 / 16.5분(6번째가 최종 지역 확정), 이후 최종 수렴. 총 20~25분 `[제안]`.
- **warning**: 확정 105초 전 사이렌+방송+지도 점멸 `[제안]`.
- **전선**: 확정 지역의 해안·이미 오염된 이웃 경계에서 출발해 지형 비용을 따라 안쪽으로 퍼진다. 속도 평지 60 / 도로·다리 100 / 급경사 30 m/분, 강 ×0.6, 단계마다 +5%, 최종 지역 수렴 ×0.7 `[제안]`. 최종 지역은 사방에서 극점으로 수렴(원이 아님).
- **데미지**: **전선이 지나간 지역 전체가 계속 위험**(전선은 그 경계). HP 100 기준 초당 단계별 2 / 3.2 / 5 / 8 / 12.6 / 20 `[제안]`. 즉사 아님. 물리 차단(벽·게이트) 없음.
- **방독 아이템**: 방독면·해독제 등 소모성, 전선을 짧게 통과 가능, 최종 지역에서는 효과 없음.
- **다리·차량**: 다리 폐쇄 없음, 차량 통행 허용.
- **연출**: 붉은 안개, 가이거 계수관 소리, 화면 효과.
- **봇**: 오염 예고를 알고 미리 이동해 최종 지역으로 수렴.
- **복제**: 서버가 시드와 서버 시간으로 결정론 계산, 클라이언트에는 지역 단계와 전선 상태만 복제.
- 폐기(이전 SPEC): lockdown·red-zone 폭격·건물 출입 봉쇄·구역당 출구 1개·소구역 순차 폭격.

### 3-1. 최종 지역 정보 공개
- 최종 지역은 서버가 매치 시작 시 결정하고 **처음엔 숨긴다**. 초반에는 오염되는 지역만 순서대로 경고(최종 지역은 모름), 남은 지역이 줄며 후보가 좁혀지고, 마지막 2~3개 남으면 남은 지역이 곧 최종 후보.
- 최종 지역의 수렴 지점은 지역 내부 도심/광장/능선 등 후보를 데이터로 정한다.

### 3-2. 최종 지역별 균형
이전의 지역별 균형표(산악·지하·온실)는 폐기. 새 6개 지역의 균형은 구현 후 플레이테스트에서 정한다. 관찰할 것: 북령 산악 저격 과다, 청람읍권 시가전 쏠림, 서남 포구 고립, 동령 고원 채석장 교전.

### 3-3. 지역 연결 보장
오염 순서가 랜덤이어도 남은 지역끼리는 **육로(국도 연결 그래프)로 항상 이어져야 한다**. 테스트: 임의 시드·임의 순서에서 남은 지역의 연결성 유지(이웃 그래프: `docs/bible/data/map.json`).

## 5. 엘리베이터
### 5-1. 투입 (ADR-055 유지)
- 승강장 20곳(지역별 3/4/3/3/4/3) × 승강기 3기 = 슬롯 60. 매치 시작 때 서버가 시드로 참가자를 무작위 지역의 엘리베이터에 배정(지역별 시작 인원 상한 = ceil(전체/지역 수)+1, 1대에 1명, 스쿼드는 팀 단위).
- 문이 열린 뒤 6초 스폰 보호(사격·투척하면 해제).

### 5-2. 탈출 — 열쇠 엘리베이터 (ADR-170)
- **열쇠**: 판당 6~8개 무작위(희귀 파밍+보급상자), 먼저 오염될 지역에 덜 배치(편중 0.5).
- **순서**: 열쇠 보유자가 승강장 버튼 앞에서 열쇠 삽입 → 엘리베이터 활성화 → 문 열림 → **30초 카운트다운**(탑승 완료 시 보유자가 문을 수동으로 닫을 수 있음) → **지역 선택(15초 안에 못 고르면 무효, 열쇠는 돌려받고 문이 닫히며 승강장은 재충전)**.
- **탑승**: 문이 열린 동안 **누구나(적 포함)** 탈 수 있고 한 대 최대 4명.
- **목적지**: 본인이 선택한 **비오염 지역**의 승강장(오염 지역으로는 불가).
- **전력 충전**: 전선이 닥친 지역의 승강장은 작동하되 1회 사용 후 90초 충전 동안 사용 불가. 열쇠 사용 후 팀 쿨다운 3분 이상 `[제안]`.
- **도착 보호 없음**(매복 위험). 봇도 열쇠를 줍고 전선이 임박하면 사용.
- 도로·다리로 걸어서/차로 탈출하는 것은 계속 가능.
- 차량: 승용차 4종·스포츠카·오토바이 2종 등(`docs/bible` 차량). 모델 CC-BY(크레딧 화면 필수), 실존 브랜드/차종명 금지.

## 6. 사망 / 부활 (칩, ADR-171)
- **스쿼드 한정 칩 부활**(솔로에는 부활 없음): 사망 시 칩 드롭, 팀원이 수거해 부활.
- **각 지역 승강장에 칩 보관함**. 사망 후 90초까지 수거 가능. **그 지역이 오염 확정되면 칩 파괴**. 부활은 **비오염 지역 승강장에서 승강장을 선택**해 한다.
- 기절·부활(수혈)은 현재 구현돼 있고 유지. 칩 부활은 구현 필요(기절 중 수혈과의 관계는 구현 때 정리).

## 7. 시점 / 카메라
- 배틀그라운드와 동일: TPP/FPP 전환, 카메라는 교체 가능한 컴포넌트, 카메라 충돌, 실내 처리(벽 관통 방지, 근접 시 FPP 권장).
- 에임(견착·조준)/반동/확산, Q/E 기울이기(기울인 쪽으로 카메라 어깨 전환, ADR-045), 엄폐 기반 교전.

- 스탯: 이름·대미지·탄약(mm)·탄속(m/s)·**저지력**(맞은 상대의 조준 흔들림·이동 감속, 1~10)·RPM·DPS·사격 모드. 총마다 달라야 한다.
- 투척물(파편·연막·섬광), 유틸(회복·방어구·열쇠·칩·방독 아이템), 근접 무기(마체테 등)는 정의서 참조.
- 신규 총기 이름은 가칭. 상표 충돌 검토는 사람이(규칙 8). 모델은 CC0 조사 후 교체(실제 총 이름·마크 제거). 상세: ASSETS.md.

## 9. 아트 방향
- 성인이 해도 유치하지 않은 **세미리얼**(배그급 몰입, 극사실 아님). 카툰/로우폴리 장난감 느낌 아님.
- **Poly Haven 중심 PBR 재질**(표면 12분류), 맑은 낮 하늘(Kloofendal HDRI), 중간 폴리 모델, 텍스처 2K 상한, 포스트프로세싱 절제(ADR-174).
- **캐릭터는 Humanoid 실사 비율**(ADR-173): Mixamo 사실풍 + UBC, LOD 3단. 소총은 실물 길이 비례.

## 10. 오디오 방향
- 현실적이고 묵직한 총성/환경음. 현재 소리는 교체 대상(준환이 후보를 직접 듣고 선택).
- 공간음향: 같은 건물의 다른 층·벽 너머 상대의 발소리 방향과 거리가 들려야 한다(바닥 차폐, 벽 폐색, 실내/실외 잔향, 표면별 발소리).
- 오염 경고 사이렌·방송·가이거 계수관이 게임플레이 단서. 상세: AUDIO.md, 정의서 사운드.

## 11. 요구 사양 (추정, M0에서 실측 후 확정)
- 최소: 내장 GPU / RAM 8GB / 30fps. 권장: GTX 1650 / RX 6500 XT급 / RAM 16GB / 60fps (1080p 상당).
- 개발 장비: **M4 Pro 맥북**(2026-11 변경). 성능 예산(PERF_BUDGET)은 그대로 유지, 411채·50인 규모는 측정 후 확정.

## 12. 비범위(지금 안 함)
웹 빌드, 모바일, 보이스챗, 랭킹/시즌, 결제, 모드 지원, 깊은 물/보트, 봇의 차량 운전, 봇의 창문·옥상 사용(NavMeshLink), 종교 랜드마크, LMG 일반 파밍, 듀오 모드.
