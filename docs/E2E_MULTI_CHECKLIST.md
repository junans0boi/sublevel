# 멀티 종단 시험 체크리스트 (#389~#392)

준비물: 구글 계정 2개(A, B, 둘 다 닉네임 설정), Mac 2대 또는 Mac 1대 + 두 번째 런처 계정이 가능한 환경, 런처 0.1.5 이상, 서버(오라클)에 r3 게임 서버와 백엔드 배포 완료.
토큰·키는 화면이나 채팅에 붙여넣지 않는다.

## 0. 서버 상태(에이전트/준환)
- [ ] 백엔드 헬스: `https://sublevel.steady2vivid.kro.kr/api/` 응답, `MAX_CONCURRENT_MATCHES` 확인(기본 1).
- [ ] 게임 서버 환경에 `SUBLEVEL_TOKEN_SECRET`(= 백엔드 `TOKEN_SECRET`), `BACKEND_BASE_URL`, `INTERNAL_API_KEY`가 있다(값은 서버 env 파일에만).
- [ ] 서버 로그에 `[Server] backend matches: only assigned accounts may join` 와 `results: sending to the backend`.

## 1. 로그인 (#389)
1. [ ] 런처 실행 → 구글 로그인 → 게임 실행.
2. [ ] 게임 메인 메뉴 알림 벨을 누르면 친구 서랍이 열린다(열리지 않고 "로그인하면…" 토스트면 토큰 전달 실패 → 런처 버전/`SUBLEVEL_GAME_TOKEN` 확인).
3. [ ] 로그인 없이 게임 exe를 직접 실행한 경우: 서버에 접속하면 "로그인이 필요하다"로 거절된다.

## 2. 친구·파티 (#391) — A와 B 두 클라이언트
1. [ ] A: 서랍의 입력칸에 B의 닉네임 → "친구 추가". B 서랍(최대 5초 안에)에 "친구 요청"이 뜬다.
2. [ ] B: "수락". 양쪽 친구 목록에 서로 "로비"로 보인다(접속 상태 20초 하트비트, 반영에 최대 20초).
3. [ ] A: B 옆 "초대". B 서랍(2.5초 안에)에 "파티 초대" → "수락". 양쪽에 "파티 2/4", A에 ★(파티장).
4. [ ] B가 파티를 "파티 나가기" → 양쪽에서 반영. 다시 초대·수락으로 복구.
5. [ ] 오류 문구: 없는 닉네임 추가 → "그 닉네임의 플레이어가 없다."

## 3. 매칭 → 배정 → 접속 (#392)
1. [ ] 파티(A 파티장, B 멤버) 상태에서 A가 로비의 시작/매칭 버튼을 누른다. 문구가 "인원을 모으는 중 · n초 뒤 봇으로 채워 시작"(또는 서버가 가득 찼을 때 "n번째").
2. [ ] B 화면에도 같은 대기 문구가 나온다(파티원이 티켓을 이어받음).
3. [ ] 배정되면(기본 15초) 두 클라이언트가 자동으로 서버 방에 접속하고 서버 대기열 문구로 바뀐다. 서버 로그: `[Server] backend match m-…`가 판 시작 때, 방 접속 로그에 두 사람.
4. [ ] 닉네임이 방 목록에 토큰의 닉네임으로 보인다.
5. [ ] 판 시작 후 A와 B가 **같은 팀**이다(HUD 팀 표시/엘리베이터 같은 칸). 서버 로그: `queue closed: … teams`.
6. [ ] 취소: 다른 파티로 매칭 후 "취소" → 서버 대기열·백엔드 티켓이 사라진다(`GET /api/match/tickets/current` 404).
7. [ ] 배정되지 않은 계정 C가 서버 주소로 직접 접속 시도 → "이 서버에 배정된 판이 없다".

## 4. 판 종료 → 결과 (#390)
1. [ ] 한 판을 끝까지 하거나 서버 로그 `match decided`가 나올 때까지 진행.
2. [ ] 서버 로그: `results: 2 people queued for the backend (m-…)` → `backend answered 200`.
3. [ ] 사이트/API: `GET /api/me/results`(또는 내 정보 페이지)에 순위·킬·생존시간이 보인다. A, B 모두.
4. [ ] 백엔드의 해당 판이 finished이고 다음 티켓이 배정 가능하다(`GET /api/match/matches?status=active`에서 사라짐).
5. [ ] 백엔드를 잠시 내렸다 올린 뒤에도(결과 전송 중 장애) 결과가 들어온다: 서버 `results-outbox` 폴더에 파일이 남았다가 지워진다.
6. [ ] 봇은 기록되지 않는다(결과 행 수 = 사람 수).

## 알려진 한계(실패해도 버그가 아님)
- 12시간 넘게 켜 둔 게임은 토큰 만료(401) → 런처에서 다시 실행.
- 판이 결정되기 전에 연결이 끊긴 사람은 결과에 빠질 수 있다.
- 서버는 한 대·동시 판 1개. 판 중에는 다음 파티가 "서버가 가득 참"으로 대기.
- 친구 패널 화면 배치는 실제 화면으로 처음 확인하는 것이다. 어긋나면 스크린샷을 남겨 달라.
