# PUBG_GAP_V2 — 배틀그라운드 대비 차이 목록 v2 (2026-11-14)

기준: `main` f1240a6의 **코드와 데이터**(`D/rules.json`·`weapons.json`·`loot.json`·`optics.json`)를 직접 읽은 결과 + 배그 위키(pubg.fandom.com, 패치 노트 인용) 조사. v1(`PUBG_GAP.md`)의 P0 대부분은 이미 들어갔다(앉기·엎드리기·헤드샷·방어구·투척물·회복 시간·킬 로그·지도·봇·봉쇄·차량·기절/부활).
- 경로 약어: `S/` = `Assets/_Project/Scripts/`, `D/` = `Assets/_Project/Data/Resources/GameData/`.

- 우선순위: **P0** = 처음 몇 분 안에 배그 플레이어가 위화감을 느끼는 감각·공정성 / **P1** = 중요한 시스템 / **P2** = 마감.

## 2. 우선순위별 작업 패키지 (병렬 가능, 파일 소유 분리)

공통 규칙(v1 4-1 유지): 패키지는 **자기 소유 파일만** 고친다. `D/rules.json`·`S/Core/GameRules.cs`·`S/Net/GameData.cs`·에디터 빌더·씬·프리팹·`FeelCapture`는 통합 에이전트만. 각 패키지는 자기 규칙 클래스에 기본값을 둔다. `docs/DECISIONS.md`는 마스터가 ADR 먼저. `S/Gameplay/PlayerController.cs`·`S/Net/Combatant.cs`는 여러 패키지가 걸리므로 **배선 메모로 넘기고 통합 때 한 번에** 고친다.
