# 봇 AI 점검표 (배그 대비) — #149, ADR-117

점검 시점의 코드(`AI/BotController*.cs`, `Core/BotBrain.cs`, `Core/BotRules.cs`)를 배틀그라운드식 행동과 견준 표. "조치" 칸이 이번 티켓에서 한 일이고, 하지 않은 것은 이유를 적었다.
판정 기준: **있음**(배그와 비슷하게 동작) / **부분**(있지만 단순) / **없음**.

## 난이도 3단계 (`Core/BotRulesDifficulty.cs`)

보통 = 데이터 파일 값 그대로. 쉬움·어려움은 그 값에 아래 배율을 곱한 복사본이다. 설정은 매치가 시작할 때(봇이 생길 때) 읽는다.

| 값 | 쉬움 | 보통 | 어려움 |
|----|------|------|--------|
| 반응 시간 (`ReactionSeconds`) | x1.8 (0.81초) | 0.45초 | x0.55 (0.25초) |
| 조준 오차 (`AimError*`) | x1.8 | 1.2~2.6도 | x0.55 |
| 회전 속도 | x0.6 | 240도/초 | x1.5 |
| 시야 거리·근접 감지 | x0.7 | 70m / 3m | x1.15 |
| 시야각 | x0.85 | 110도 | x1.05 |
| 청력(발소리·총성) | x0.7 | 14m / 80m | x1.2 |
| 감지 주기 | x1.5 (느림) | 0.15초 | x0.7 |
| 점사 쉬는 시간 | x1.3 | 0.3~0.8초 | x0.7 |
| 투척 간격 | x1.5 | 6초 | x0.7 |

## 20마리 시나리오 (끼임·멈춤)

`MatchSimulationTests`를 `MATCH_SIM_BOTS=20`으로 돌린다(월드 장면, 봉쇄 빠른 진행, 시간 2배). 3초마다 살아 있는 봇의 위치를 보고, 싸움·치료·후퇴 중이 아니면서 45초 동안 1.5m 안에 머문 봇을 "멈춤"으로 센다(초반 60초는 승강기·첫 파밍이라 제외). `BotStats`의 끼임(stall) 합계와 함께 검증한다. 결과는 `docs/PROGRESS.md`와 커밋 메시지에 적는다.
