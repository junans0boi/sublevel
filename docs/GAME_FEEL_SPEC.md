# GAME_FEEL_SPEC — 조준·이동·전투 감각 기준 (배틀그라운드 참조)

원칙: 준환은 배그를 잘 안다. "비슷하게"가 아니라 **배그 플레이어가 위화감 없이 쓰는 수준**이 목표. 수치는 전부 데이터 파일(`rules.json` 계열)에 두고 보수적(작게) 시작해 플레이 피드백으로 조정한다. 아래 수치는 **시작값 제안**이며 출처 있는 사양이 아니다. 감으로 검증한다.

## 1. 조준(ADS)
- 우클릭 **꾹**: 누르는 동안 견착(조준 유지), 떼면 해제.
- 우클릭 **탭**(짧게): 조준 시점 토글. 한 번 더 누르면 해제. 꾹/탭 경계 약 0.2초(조정 가능).
- 견착 시: 이동 속도 감소, 탄퍼짐 감소, 반동 감소, FOV 소폭 감소. 전환은 부드럽게(0.1~0.15s).
- **조준선(가늠쇠/레티클)**: 견착 시 화면에 조준 표시가 보여야 한다. TPP에서는 크로스헤어 수축, FPP/탭 토글 시점에서는 무기의 조준 시점으로 카메라가 붙는다(구현 방식은 세션 판단, 단 "조준 시점이 달라졌다"는 것이 눈에 보여야 한다).
- 사격 중 조준 해제/재조준 시 끊김 없어야 한다.

## 2. 크로스헤어/탄퍼짐
- 비조준(허리사격)은 크로스헤어가 넓고, 이동·사격 시 벌어지고, 정지 시 수축.
- 조준은 좁다. 히트 시 아주 짧게(≈0.1s) 변화(히트마커 참조 §5).

## 3. 기울이기(Q/E) — PT-3에서 "과함" 지적
배그식: **누르는 동안** 몸과 카메라가 옆으로 기울고, 기울인 채 사격 가능, 떼면 복귀. 과장되면 어색하므로 **작게** 시작:
- 기울기 각도 시작값 10°(과하면 8°), 좌우 오프셋(카메라/몸) 0.25m 이하, 진입/복귀 0.10~0.15s.
- 카메라가 머리 위치를 따라 옆으로 넘어가고, 무기가 엄폐물 모서리 너머로 노출되는 느낌.
- TPP/FPP 모두. 기울인 상태에서의 탄 발사 원점은 **기울어진 카메라/총구 기준**으로, 엄폐물 위/옆으로 탄이 넘어가는지 테스트로 확인한다.
- 기울임 중 이동 속도 소폭 감소.
- **현재 값(ADR-048)**: 좌우 0.25m, 상체 10°, 카메라 기울기 눈 위치 시점 6°·TPP 0°, 진입 0.125초, TPP 카메라는 오른쪽 어깨 고정. `rules.json`의 `Lean`.

## 4. 이동·애니메이션
- 8방향 이동: 현재 전/후/좌/우 4클립 블렌드(ADR-046). 대각선에서 다리 왜곡이 없어야 한다. 불가하면 하체 보정 또는 방향별 재생 속도 정규화.
- **발소리는 발이 닿는 순간**(애니메이션 이벤트 또는 위상 기준). 걷기/달리기/웅크리기/조준 이동에서 모두 빠지지 않을 것. 재질(콘크리트/금속)별 변주는 후순위.
- 다리 재생 배율(클립 속도 ↔ 이동 속도)은 상한을 둔다. 너무 빨라 보이면 이동 속도 조정을 ADR로.
- **점프 애니메이션**: PT-3에서 없다고 지적. 점프 시작/체공/착지 필요. 사용 가능한 클립이 없으면 기존 클립 조합(무릎 굽힘 보정)·절차적 보정 중 단순한 방법으로 처리하고 한계를 기록. 파쿠르/넘기는 SPEC 범위 밖(후순위).
- 상체 레이어: 이동 중 준비 자세(총 내림), 조준/사격 시 조준 자세, 빈손 일반 자세(M1.6a 반영됨). 손-총 어긋남은 무기별 오프셋으로 조절, IK는 후순위.

## 5. 전투 피드백(M1.6b 핵심) — "총알이 나가는 것도 맞는 것도 안 보임"
최소 기준(모두 서버 권위 사격 결과를 기준으로 클라이언트 연출):
1. **총구 화염**: 2~3프레임 스프라이트 + 아주 짧은 포인트 라이트(≤0.05s). 무기별 크기 차이. 소음기 개념은 후순위.
2. **트레이서(탄도선)**: 얇고 밝은 선이 총구에서 명중점까지 빠르게 이동(수명 ≈0.05~0.1s, 매 발 또는 N발마다). **머티리얼이 있는 URP Unlit(가산) 머티리얼 + 텍스처/그라디언트**. 원거리에서도 보이도록 길이/폭 최소값 유지.
3. **표면 임팩트**: 맞은 표면에 따라 파티클(콘크리트 분진, 금속 스파크), 탄흔 데칼(수 제한, 풀링). 표면 구분은 레이어/물리 머티리얼. 성능 예산 안에서(PERF_BUDGET).
4. **히트마커**: 적중 시 크로스헤어 주변 X 표시 ≈0.1s + 짧은 히트음. 헤드샷/킬은 색/크기 다르게(빨강, 킬 확인음). 선정적 표현은 쓰지 않는다(혈액/신체 훼손 표현 없음, 가벼운 피격 먼지/플래시 정도).
5. **피격 반응**: 적/더미가 맞으면 몸이 살짝 반응(플래시, 짧은 모션). 플레이어 피격 시 화면 가장자리 피격 방향 표시, 짧은 카메라 흔들림.
6. **탄 소리**: 총성 외에 임팩트음(표면별 2~3종). 총알이 스쳐가는 소리는 후순위.
7. 반동: 카메라/총구 상승 + 패턴 변주. 무기별 차이가 느껴져야 한다.
- 에셋은 CC0 직접 다운로드(예: Kenney 파티클 팩, 확인 후) 또는 절차적 생성. `ASSET_LEDGER.md` 기록 필수.
- 성능: 이펙트 풀링, 동시 파티클 상한, GC 할당 0 목표.

## 6. 카메라
- TPP/FPP 전환, 카메라 충돌, 실내 처리 유지. 견착·기울이기와 충돌하지 않게 순서 정의.

## 7. 완료 판정(타이틀 공통)
자동 테스트 통과 + **준환이 5분 직접 플레이해서 "배그 하던 사람이 이상하다고 느끼지 않는다"**. 세션은 이를 자체 검수하되 못 확인한 부분은 직접 확인 목록으로 넘긴다.
