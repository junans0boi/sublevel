# VEHICLE_SPEC — S10 차량 (2026-11-16, 가정은 ADR-198~203, master 승인 대기)

> 근거: SPEC §5-2, `docs/bible/data/vehicles.json`·`roads.json`, `MP_AUDIT_VEHICLES.md`, ADR-065·067~069·074·075·077·175, `VehicleRules.cs`(`VehicleParking`). 충돌하면 SPEC이 이긴다.
> 확인한 것 / 추정을 구분한다. 봇 차량 운전은 범위 밖(ADR-175).

## 1. 현재 상태 (확인함)
- 운행용 7종: 승용 5(세단·왜건·리프트 픽업·패널 밴·스포츠카 `GoblinV12`) + 오토바이 2. 종류(`VehicleKind`)는 Car·Motorcycle. 모델별 차이는 질량·좌석·무게중심뿐, 최고속도·가속 등은 종류별 한 벌(`rules.json`).
- 서스펜션은 WheelCollider가 아니라 Rigidbody + 바퀴별 레이캐스트(ADR-069). 지형 높이 코드에 의존하지 않는다.
- 월드 배치: 주차 지점당 1대, 차 6 + 오토바이 4, 간격 40m. 정적 소품(주차·폐차) 최대 28대, 폐차는 3대 중 1대.
- **붉은 차 캡처(`world_town_street.png`)는 버그가 아니다**: 폐차 소품 `Sport_Wreck_17`(바퀴 없음, −0.22m, 녹색조). 바운드 하단이 지면 −0.19m로 측정됨(2026-11-16 Unity). 정상 소품은 경사에서 낮은 쪽이 최대 0.25m 뜬다(`GroundUnder`=최고 모서리).
- 인게임 이름은 종류만(dv1 확정), 색 변형 3~5색(dv2 확정)은 아직 미구현.
