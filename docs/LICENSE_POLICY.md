# LICENSE_POLICY — 라이선스·상표 정책

## 허용
- CC0 / Public Domain
- 상업 이용 가능 로열티프리(약관 확인됨)
- CC-BY (크레딧 표기 가능한 경우만, 크레딧 화면에 자동 반영)
- SIL OFL(폰트)
- MIT/Apache-2.0/BSD (코드 패키지)

## 금지
- NC(비상업), ND(변경 금지, 우리는 수정이 필요), Editorial Use Only, Reference Only
- 라이선스 불명/출처 불명
- GPL 계열 코드의 링크(배포 의무) — 법적 검토 없이는 금지
- 실존 상표·로고·제품명(총기 제조사/모델명, 자동차 브랜드/차종명, 기업명)
- 실존 작품(영화·게임·소설)의 고유명사/캐릭터/미술 복제
- AI 생성물의 최종 빌드 포함

## 판단 흐름
```
라이선스 명시? ─아니오→ 사용 금지
   │예
CC0/PD? ─예→ 사용 (ledger 기록)
   │아니오
상업 가능 + 수정 가능? ─아니오→ 사용 금지
   │예
크레딧 필요? ─예→ CREDITS에 자동 반영 + ledger 기록
   │아니오
ledger 기록 → 사용
애매하면 → needs-license-review 라벨, 사용 보류
```

## 상표 위생
- 총기: 실제 모델 형상은 참고만, 이름/각인/제조사 마크 제거, 오리지널 명칭(예: "MK-9 계열 같은 내부 코드명").
- 차량: 일반 분류명만. 엠블럼/그릴 모양 모방 금지.
- 게임명·로고: 출시 전 상표 검색은 사람이 수행(RISKS).
