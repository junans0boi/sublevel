## M1.6a-fix 자체 검수 기록 (2026-11-13, 세션)
방법: mac 빌드를 `-feelcapture`로 실행해 화면 53장 저장 → 직접 열어 확인. 포즈 시트(`CharacterKit.RenderClipSheet`)로 클립 확인.
| 본 것 | 결과 |
|---|---|
| 조준(탭) 화면 | 수정 전: 시야만 좁아지고 아무것도 안 보임 → 무기가 중앙 아래에 보이고 점 조준선 |
| 지향/견착/산탄총 조준선 | 벌어짐이 서로 다름(산탄총이 가장 넓음) |
| TPP 기울이기 | 카메라가 어깨를 넘지 않음. 기울기는 눈에 띄게 작음(정지 화면에서는 거의 안 보일 정도 — 너무 작은지는 사람 확인) |
| 제자리·달리기 점프(옆 시점 8장) | 공중에서 다리를 벌린 포즈 유지, 착지 후 서는 자세. 제자리 점프도 달리는 포즈라 도약처럼 보임(한계) |
| 옆 이동(뒤·위 시점) | **수정 전: 몸 전체가 옆을 보고 달림. 조준하면 총이 약 25° 오른쪽** → 수정 후 다리만 돌고 총은 정면 |
| 걷기·달리기(옆 시점) | 포즈 정상. 다리 속도·발 미끄러짐은 정지 화면으로 판단 불가(사람 확인) |
세션이 **확인하지 못한 것**: 움직임의 느낌 전부(기울이기 속도, 다리 속도, 허리 비틀림이 움직일 때 어떻게 보이는지), 소리, Windows 동작.

## 아직 사람이 확인하지 않은 것 (최신 목록은 `docs/PROGRESS.md` "사람이 직접 확인할 항목")
1. Alt+F4/닫기 버튼으로 종료해도 새 매치로 시작하는지, Windows에서 `Sublevel.exe`가 남는지(Windows PC 필요)
2. 꾹/탭 구분 0.2초가 손에 맞는지, 견착 지연이 거슬리지 않는지
3. 무기별 반동, 조준 시 반동 감소
4. 기울인 채 사격하면 탄이 엄폐물을 넘는지
5. 대각선 이동에서 다리 왜곡이 사라졌는지(M1.6a-fix에서 방식이 바뀜: 다리 돌림)
6. 발이 닿는 순간에 발소리가 나는지, 느린 이동·게걸음에서 빠지지 않는지
7. 총을 내린 자세에서 총이 손에서 벗어나 보이지 않는지(IK 없음)
8. **다리 속도**: M1.6a-fix에서 배율을 1.3~1.7배(상한 1.75)로 낮춤. 이동 속도는 그대로(4.5/7.0m/s)라 발이 조금 미끄러진다. 여전히 어색하면 이동 속도 조정을 검토(ADR 기록).
