# HISTORY_AND_LESSONS — 결정 경위와 교훈

## 1. 컨셉이 정해지기까지
- 출발: 배틀그라운드 + 카트라이더/이니셜D를 좋아함 → 레이싱 vs 배틀로얄 고민 → "엄폐·수류탄·총, 팀플"이 핵심 재미임을 확인 → **배틀로얄로 확정**, 레이싱/차량은 후순위.
- 메이즈러너에서 착안: 거대한 시설 안, 엘리베이터 투입, 구역 이동. 단 **세계관·이름은 오리지널**.
- **폐기**: 움직이는 미로 벽(유저 피로). → 순차 구역 폐쇄(레드존 폭격식).
- **폐기**: 봉쇄 즉사. → 방사능 지속 데미지, 열쇠 또는 구역당 정확히 1개 출구(매 판 랜덤, 2단계 힌트).
- 칩 부활(팀 모드), 칩 보관함(90초), 폐쇄 순서·**최종 구역 매 판 랜덤**(중앙 코어 고정 금지), 허브형 엘리베이터.
- 시점: 배그와 동일(TPP/FPP 전환).

## 2. 기술 결정 경위
- 처음 웹(Three.js)을 권했으나 준환이 "웹 1순위 아님, PC 전용"이라 해서 **Unity**로 전환. Godot 4는 폴백.
- 준환이 "Unity 멀티는 Photon뿐, 20명 한계"라고 알았는데 사실이 달랐음 → Fish-Net/Mirror 무료, Photon 무료 100CCU. **Fish-Net 선택.**
- 에이전트 자율 개발 결정: 개발 장비 MacBook Pro 13" M1. 구현은 Unity 에디터 커맨드라인(batchmode).
- **Unity 버전 혼선**: 처음 Hub CLI로 6000.3 설치가 불완전해 보였고(실제로는 완전 설치), 6000.6으로 프로젝트가 만들어졌다가 6000.3.28f1로 재생성. 6000.6은 LTS가 아닌 Supported 릴리스(6.7 LTS 직전)라 6.3 LTS 유지. **교훈: 에이전트의 "설치 불완전" 보고를 사실 확인 없이 믿지 말 것.**
- **Fish-Net 4.7.4**가 Unity 6에서 컴파일 에러 → 4.7.3 고정(ADR-019). 수정판이 나오면 해제 검토.
- **스킬 호출 제약**: mattpocock/skills의 wayfinder, to-spec, to-tickets, implement 등은 작성자가 user-only로 잠가 Skill 도구로 호출 불가 → SKILL.md를 직접 읽어 따른다(ADR-022).
- 한 프로세스에서 Fish-Net 서버+클라이언트 batchmode 스모크 통과(M0-6), M0 게이트 통과로 Godot 폴백 불필요.

## 3. 에셋/룩 경위
- 소스 정책은 ASSETS.md/AUDIO.md. 가입·결제 필요한 소스(Sonniss, Mixamo, itch.io 결제 위젯)는 에이전트가 못 받는다 → 사람이 받아야 함(HUMAN_TODO).
- 룩 검수에서 지적한 것: 사진 기반 PBR 배경 + 플랫 셰이딩 로우폴리 캐릭터 = **스타일 불일치**. 노멀 재계산, 머티리얼 분리, 포스트프로세싱(Neutral 톤매핑, 약한 SSAO, 비네트, 그레이딩), 방향광+보조광으로 완화해 승인. 바닥 반사 얼룩, SSAO 얼룩은 후속 수정.
- 캐릭터 소스(Quaternius Swat)는 **현실적 하한선**. 더 나은 캐릭터는 유료/직접 제작 예산이 필요할 수 있음 → 예산은 준환 결정.
- 애니메이션 클립은 대각선 전용이 없어 4방향 블렌드로 대각선 처리(ADR-046). 점프 클립 유무는 확인 필요.

## 4. 성능 판정 교훈
- "프레임 제한 해제 시 p99"와 "60Hz 고정 시 누락 프레임"을 섞어 "예산 안"이라 말한 적이 있다. ADR-041에서 판정 조건을 명문화했다. **새 수치를 보고할 때는 항상 조건(해상도, 프레임 제한, 에디터/플레이어 빌드)을 함께 적는다.**
- 에디터 오프스크린 값은 참고용. 합격 판단은 mac 플레이어 빌드 측정.
- SSAO가 프레임 비용의 절반 → 빠듯해지면 먼저 끈다.
- 66.7ms 단발 프레임(M1 때) 원인은 미조사. 구역 D 이후 반복되면 `perf` 티켓.

## 5. 환경 교훈
- 준환 맥에는 처음 Homebrew, gh, claude가 없었다(지금은 설치됨). 프로젝트 경로 `/Volumes/WorkSpace/Project/sublevel`(외장 볼륨 가능성, 임포트가 느리면 SSD 확인).
- 터미널에 `#` 주석 줄을 붙여 넣으면 zsh가 파싱 오류를 낼 수 있으니 준환에게 명령을 줄 때 주석 줄을 빼거나 따로 설명한다.
- 재실행 시 "이어서 시작" 버그의 원인은 고정 포트(앞 인스턴스가 살아 있으면 그 매치에 접속). 실행마다 빈 포트로 수정됨(M1.6a).

## 6. 반복하지 말 실수
1. 자동 테스트 통과 = 완료로 보고 → 직접 플레이하면 HUD 텍스트뿐, 총알/피격 안 보임, Esc=종료, 인벤토리 없음. **"게임으로서 플레이 가능한가"를 체크리스트로 점검한다.**
2. 임시 구현을 임시라고만 쓰고 넘김 → 사람이 해보면 가장 먼저 거슬리는 것이 임시 구현. 임시 구현은 GAME_FEEL/UI_SPEC의 최소 기준을 충족시킨 뒤 "임시"로 남긴다.
3. 배그 조작을 "비슷하게" 구현 → 준환은 배그를 잘 안다. 기울이기 과하다고 지적. **수치는 보수적(작게) 시작, 데이터 파일로 조절.**
4. 에셋 소스 가입 장벽을 늦게 발견. 소스 선정 시 "무가입 직접 다운로드" 여부를 먼저 확인.
5. 모호한 지시 해석 불일치("타일링 스케일을 줄여라" 해석). 모호하면 합리적 해석 + 기록, 반대 해석이었을 때 되돌리기 쉽게.
