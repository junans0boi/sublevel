# 비(非)인게임 UI/UX 시안 노트 (2026-11-16, 제안 단계)

열기: `docs/research/ui_mockups/index.html` (file://로 동작, 외부 의존 없음). 게임 이름·로고는 자리표시.

## 파일
- index.html: 허브 + 결정 시트(라디오 + "내 선택 복사")
- proto.html / proto.js: 클릭 가능한 프로토타입 (방향·테마·레이아웃 변형 전환, Esc, 포커스 링, 키 변경, 매칭·카운트다운 진행, 오류 시험 버튼)
- compare.html: 같은 화면을 A·B·C 나란히
- direction_a/b/c.html: 방향별 토큰·컴포넌트·명암비 + 화면 23장
- flow.html: 상태 흐름도(SVG) + Esc 규칙표
- ui.css(토큰·컴포넌트), ui.js(화면·데이터), gallery.js

## 세 방향
- A 시설 관제실: 앰버 강조, 모노스페이스 레이블, 모서리 괄호, 스캔라인, 사선 컷 버튼, 격자·등고선 배경.
- B 클린 모던: 파랑 강조, 반투명 블러 패널, 알약형 컨트롤, 큰 타이포.
- C 80년대 레트로: 주홍 강조, 명조 제목, 이중선·그림자 판, 하프톤·종이 질감, 약한 CRT 비네트.

## 2차 수정 (준환 피드백, 2026-11-16)
- 어둡게: 세 방향 다크 토큰을 거의 검정 저휘도·저채도로 재조정. 기본 진입은 항상 다크(허브·비교·방향별·프로토타입 모두), 라이트는 버튼으로만. 큰 면 밝은 색 제거(주요 버튼·메뉴 선택·세그먼트·인원 칸은 어두운 틴트 + 얇은 강조 테두리). 방향별 분위기: A 콘크리트 기둥·노이즈·스캔라인, B 은은한 안개·차가운 비네트, C 입자 노이즈·하프톤·갈색 비네트. 다크 스크린샷 84장 평균 밝기 약 15/255(최대 23), 밝은 픽셀(>180) 비율 1% 미만.
- 방 만들기 제거: 일반 플레이에는 방 생성·방 목록이 없음. 로비 상단 탭 '일반 매치 / 커스텀 모드'로 커스텀 모드 화면(방 만들기, 코드로 참가)만 간단히 추가.
- 로비: 모드(솔로/스쿼드) · 시점(3인칭/1인칭, SPEC 7절 유지) · 맵(청람도) · 시작 버튼. 초대하면 내가 파티장, 파티원 시점은 모드·시점 잠금 + 준비 버튼. 파티원 전원 준비 시 파티장 시작 버튼 활성화.
- 흐름: 로비 → 매칭 대기(파티장만 취소) → 인게임 로딩(맵 팁, 오염 한 줄 설명, 진행률) → 대기 구역(현재 N/50, 최소 30명이 모이면 30초 카운트다운 시작: 제안 수치, 이동·채팅·감정 표현만) → 0초에 엘리베이터 투입 → 인게임. flow.html과 proto.html(상단 '시점' 선택: 솔로/파티장/파티원)에 반영.
- 우리만의 요소: 섬 오염 현황 브리핑 카드(6개 지역·승강장 수), 승강장 위에 스쿼드 실루엣이 서 있는 로비 구도(SVG), 대기 구역의 승강기 홀, 결과 화면의 '탈출·열쇠·부활' 요약.
- 결정 시트에 '파티·매칭 흐름 확인', '어두움 정도' 추가.

## 3차 수정 (로비 상시 모드 패널, 2026-11-16)
- 문제: 모드(솔로/스쿼드)가 오른쪽 정보 패널의 작은 토글이라 시작 전에 지금 모드가 안 보였음. 해결: 시작/준비 버튼 바로 위에 상시 패널 고정(스쿼드 좌측·하단·중앙·파티원 모든 레이아웃).
- 구성(위에서 아래): 지금 모드 표시 + '모드 선택 ▸' / 시점 TPP·FPP / 모드 아이콘 열(솔로 1명·스쿼드 4명만, 선택은 굵은 테두리·진한 틴트·'✓ 선택됨' 글자, 미선택은 흐림) / 맵 카드(청람도 · 6개 지역 SVG 썸네일, 좌우 화살표, 다음 맵 준비 중 잠금) / 큰 시작·준비·매칭 취소 버튼. 기존 정보 패널의 모드·시점·맵 토글은 삭제(중복 제거).
- 파티원: 모드·시점이 잠기고(자물쇠 + '파티장이 정한 모드입니다') 현재 모드는 계속 보임.
- '모드 선택 ▸' → 게임 모드 선택 창(왼쪽 목록 솔로/스쿼드, 오른쪽 설명 + 맵 카드 2장), Esc로 닫기.
- 승강장 위 SVG 실루엣 머리 위에 이름표 + ✓ 준비 완료 / … 준비 중 / ♛ 파티장 표시. 하단 슬롯 목록 유지.
- 상단 2단 탭: 큰 탭(플레이/외형/설정) + 서브탭(일반 매치/커스텀 모드). 방 목록 없음.
- 프로토타입: 모드 아이콘 클릭으로 솔로↔스쿼드 즉시 전환, 솔로면 파티 UI 접힘, 스쿼드면 빈 슬롯 표시.
- 결정 시트에 '모드 상시 패널 위치/구성 확인' 추가.
- 새 화면 항목: lobby-solo(파티 접힘), lobby-mode(모드 선택 창), lobby-member-b(파티원 하단 배치).

## 4차 수정 (상단 고정 메뉴 + 로비 단일 구조, 2026-11-16)
- 폐기: 로비 3레이아웃(스쿼드 좌측/하단/중앙), 오른쪽 정보·매칭 패널, 메인 메뉴 3레이아웃(좌측 세로/하단 가로/중앙 카드). 결정 시트의 해당 레이아웃 선택지도 삭제. 메인 메뉴 화면은 없애고 **로비를 메인 진입 화면으로 통합**(로딩이 끝나면 바로 로비, 종료는 상단 전원 아이콘 또는 Esc 확인).
- 상단 고정 메뉴 바(공통 컴포넌트 topbar): 왼쪽 로고 자리표시, 가운데 탭 플레이/외형/훈련장/설정/크레딧(플레이 아래 서브탭 일반 매치/커스텀 모드), 오른쪽 핑·이름·알림·설정 톱니·종료. 로비·외형·훈련장·설정·크레딧·커스텀 모드에 동일 위치로 적용. 재화·상점 없음.
- 배경: 승강기 홀 + 열린 게이트 뒤 어두운 노을 하늘(CSS/SVG), 방향별 질감만 다름.
- 로비 구조: 왼쪽 위 '오염 현황 브리핑' 소형 카드, 왼쪽 아래 폭 340px 상시 패널(시점 TPP|FPP → 솔로/스쿼드 모드 칸 → 청람도 맵 카드(좌우 화살표, 썸네일, 다음 맵 잠금) → 매칭 상태 한 줄 + 인원 막대 → 큰 시작/준비/매칭 취소 · 시간 버튼), 가운데 승강장 위에 파티 실루엣(내 캐릭터가 가운데에서 가장 크게, 머리 위 이름표 + ✓/… + ★ 파티장, 빈자리는 점선 + '+ 초대'), 오른쪽 아래 큰 로고 자리표시, 맨 아래 얇은 바(Enter 채팅 힌트, 채팅·친구 버튼, 파티 4칸, 인원 수).
- 상호작용: 모드 칸을 누르면 솔로↔스쿼드 즉시 전환(솔로면 파티가 접힘), 맵 카드·썸네일을 누르면 게임 모드 선택 창(왼쪽 목록 + 오른쪽 맵 카드 3장 가로). 파티원은 모드 칸·시점 잠김 + '준비' 버튼.
- 흐름(파티장 초대 → 준비 → 시작 → 매칭 → 로딩 → 대기 구역 30초 → 투입)은 그대로. flow.html 갱신.
- 구조는 요청에 따라 PUBG 로비 구성을 참고했으나 로고·문구·아이콘·색·그래픽은 모두 자체 제작.
- 상단 고정 바 적용 범위: 로비(메인 진입)·외형·훈련장·설정·크레딧·커스텀 모드. 스플래시·로딩·인게임 로딩·대기 구역·엘리베이터 투입·결과는 흐름 중간 화면이라 로고만 있는 헤더를 씁니다(결과 화면에도 탭 바를 달지는 결정 필요).
- 모드 칸 클릭은 즉시 전환, 맵 이름·썸네일 클릭은 게임 모드 선택 창을 엽니다.

## 5차 수정 (배그형 폐기, 로비 6안, 2026-11-16)
- 4차의 '왼쪽 아래 세로 패널 + 가운데 큰 캐릭터 줄 + 오른쪽 아래 큰 로고 + 하단 채팅/친구/파티 줄 + 탭 바'는 'PUBG형'이라 폐기하고 compare에 **'참고(배그형, 채택 안 함)'**으로만 남김(lobby-ref-squad).
- 상단 바를 '층 표시기'(01~05 번호 + 라벨, 선택 시 ▲ 점등, 오른쪽에 › 브레드크럼/서브메뉴)로 교체. 로고는 오른쪽 끝의 작은 표식으로 이동, 큰 로고·하단 바 제거(채팅은 ⑥의 서랍 핸들, 친구 초대는 파티 카드 안 '+ 초대'로 흡수).
- 로비 6안(모두 같은 흐름·같은 5개 상태 + 모드 선택 창):
  - ① 투입 지휘 테이블 — 한 줄 컨셉: 섬 지도가 주인공, 파티는 승강기 대기 레일, 오른쪽 투입 명령서. 장점: 지도·브리핑 학습, 설정이 한 장에 모임 / 단점: 화면이 빽빽.
  - ② 승강기 조작반 — 승강기 안에서 문을 보고 서고 아래 조작반(레버·스위치·LED 모드 표시). 장점: 세계관 몰입, 모드가 가운데 크게 / 단점: 조작반이 화면 1/3.
  - ③ 3단 매니페스트 — 명단 | 장면·매칭 | 설정 3열, 하단 중앙 긴 버튼. 장점: 예측 가능·구현 쉬움 / 단점: 평범.
  - ④ 관제 콘솔 벽 — 모니터 3대(명단, 지도+큰 모드 글자, 브리핑) + 아래 한 줄 상태 버튼. 장점: 시설 관제 톤 / 단점: 장식 틀이 공간 소모.
  - ⑤ 탑승권 — 중앙의 절취선 탑승권 한 장(모드·시점·맵·ELEV 07·좌석 4칸·바코드·스탬프 버튼). 장점: 가장 단순 / 단점: 정보량 적음.
  - ⑥ 풀스크린 지도 — 지도가 배경, 칩·모서리 카드만, 지도의 지역 버튼으로 '희망 지역(우선 고려, 보장 아님)' 선택(투입은 서버 배정). 장점: 탁 트임 / 단점: 지도 위 가독성 관리 필요.
- 배그보다 나은 UX 개선점(전 안 공통): ① 준비/시작/취소를 하나의 상태 버튼으로 통합(클릭 수 감소, 시작 버튼 라벨이 상황별로 바뀜) ② 매칭 중 '사람 N / 봇 M 채움'과 50칸 막대를 항상 같은 자리에 투명하게 표시 ③ 시작이 막힌 사유를 한 줄로 안내('서아 님이 준비 중입니다…') ④ 모드·시점·맵을 한 줄 요약 칩/표시로 시작 전부터 항상 보여 주고 눌러서 변경(모드 선택 창에서 시점까지) ⑤ 오염 브리핑·열쇠 안내·승강장 수를 로비에서 미리 학습 ⑥ 지난 매치 요약과 오늘의 목표를 로비에 표시 ⑦ 파티원은 잠긴 이유(자물쇠 + 파티장이 정함)를 같은 자리에서 확인.
