화면 흐름도 (상태 다이어그램)

실선 = 정상 흐름, 점선 + 점선 테두리 = 실패 분기, 굵은 테두리 = 허브 화면. 색이 아니라 선 모양으로 구분합니다. 화면 이름 옆 번호는 화면 목록 번호입니다.

Esc · 뒤로 규칙

화면Esc뒤로 가기 버튼비고
스플래시 · 로딩스플래시는 아무 키로 건너뜀, 로딩은 무시없음로딩 실패 시 오류 팝업
로비 (메인 진입 화면)매칭 중이면 취소(파티원은 무시), 아니면 종료 확인 팝업없음상단 탭으로 외형·훈련장·설정·크레딧 이동. 팝업에서 다시 Esc = 취소
설정 · 캐릭터 · 크레딧 · 훈련장로비로 (탭 화면은 모두 로비 하나에서 갈라짐)이전 화면설정은 적용하지 않은 변경이 있으면 확인 팝업(후속 설계)
키 변경 대기변경 취소—다른 키를 누르면 즉시 저장
투입 대기무시 (실수 방지)나가기 버튼 (포기로 처리)Tab 인벤토리 · M 지도는 열 수 있음
파티원 로비매칭 중이 아니면 종료 확인, 매칭 중에는 무시파티 나가기모드·시점은 파티장만 변경. 파티장이 시작하면 따라서 매칭 대기로 이동
커스텀 모드로비로뒤로 가기방 만들기·코드로 참가는 여기에만 있음. 방 목록 없음
인게임 로딩무시없음로딩 실패 시 연결 오류 팝업
대기 구역무시 (실수 방지)나가기 버튼이동·채팅(Enter)·감정 표현(1~4)만 가능. 사격·아이템 불가
결과로비로—같은 팀으로 다시 매칭 가능
오류 · 종료 확인 팝업닫기취소연결 끊김 팝업은 Esc로 닫히지 않음

역할별 분기와 매칭 규칙

시점로비에서 하는 일매칭 시작 조건
솔로모드·시점·맵 확인, 친구를 초대하면 내가 파티장이 됨바로 시작 가능
파티장모드(솔로/스쿼드)·시점(3인칭/1인칭) 선택, 초대, 시작·매칭 취소파티원 전원이 준비(READY)를 누르면 시작 버튼 활성화
파티원준비 / 준비 취소, 파티 나가기. 모드 선택 비활성해당 없음 (파티장이 시작)

로비 상시 패널(3차): 시작/준비 버튼 바로 위에 시점(TPP/FPP) · 모드 아이콘 열(솔로 1명 / 스쿼드 4명, 선택 강조 + 글자) · 맵 카드(청람도, 다음 맵 준비 중 잠금)가 항상 보입니다. 아이콘을 누르면 바로 솔로↔스쿼드 전환(솔로면 파티 슬롯이 접히고 스쿼드면 빈 슬롯이 생김), '모드 선택 ▸'은 게임 모드 선택 창(Esc로 닫기)을 엽니다. 파티원은 모드·시점이 잠깁니다. 상단은 큰 탭(플레이/외형/설정) + 서브탭(일반 매치/커스텀 모드)입니다.

5차: 로비는 서로 다른 6개 레이아웃(① 투입 지휘 테이블 ② 승강기 조작반 ③ 3단 매니페스트 ④ 관제 콘솔 벽 ⑤ 탑승권 ⑥ 풀스크린 지도) 중 하나를 고르며, 흐름은 모두 같습니다. 어느 안이든 모드·시점·맵이 시작 전부터 보이고 시작/준비/취소는 하나의 상태 버튼입니다. 4차: 메인 메뉴 화면을 없애고 로비를 메인 진입 화면으로 통합했습니다. 상단 고정 메뉴(플레이/외형/훈련장/설정/크레딧, 플레이 아래 서브탭 일반 매치/커스텀 모드)가 모든 비인게임 화면에서 같은 위치에 있습니다. 로비는 왼쪽 아래 상시 패널 하나뿐입니다. 흐름: 로비 → 파티장 시작 → 매칭 대기(취소 가능) → 매칭 성사 → 인게임 로딩(맵 팁, 오염 한 줄 설명, 진행률) → 대기 구역(현재 N/50, 최소 30명이 모이면 30초 카운트다운 시작: 제안 수치) → 0초에 엘리베이터 투입. 방 생성은 커스텀 모드에만 있습니다.

화면 목록

① 시작·로딩 ②③ 로비(= 메인 진입 화면)·커스텀 모드 ④ 캐릭터 ⑤ 설정(4탭) ⑥ 인게임 로딩·대기 구역·엘리베이터 투입 ⑦ 결과 ⑧ 크레딧 ⑨ 팝업(종료·오류·끊김·재접속 실패) ⑩ 훈련장·튜토리얼. 인게임 HUD, 일시정지(Esc) 메뉴 안의 설정 호출은 범위 밖입니다.
