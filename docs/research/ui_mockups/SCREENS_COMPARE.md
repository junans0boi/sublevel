# 화면별 시안 대조 (크레딧·커스텀·팝업·토스트, 2026-11-16)

## 방법 (모든 화면 공통, 새 도구)
`tools/mock_export.js`가 확정 시안 `adopted.html`의 한 화면을 브라우저에서 읽어 **모든 박스(채움·테두리·모서리·그라디언트·아래 막대), 글자(상자 좌표·크기·굵기·색), 이미지(SVG→PNG)**를 1920×1080 무대 좌표로 JSON으로 내보낸다(`Resources/Ui/Screens/*.json`). Unity의 `MockScreen`이 그 JSON을 그대로 uGUI로 그린다(측정값 = 구현값). 시안에서 클릭 가능한 요소(`data-act`/`data-go`)는 버튼이 되고, 라이브 데이터가 필요한 부분만 코드로 바꾼다. 해상도는 무대 컨테이너(`StageFit`)가 맞춘다(16:10 상하 여백, 21:9 가운데).

위 수치는 같은 JSON에서 만든 것이라 좌표 차이는 0이고, 글꼴(시안 시스템 폰트 → Noto Sans KR 굵기 1단계)로 인한 글자 폭 차이만 있다.

## 동작 (눌러도 아무 일도 없는 버튼 없음)
- 알림 버튼 → 토스트 "새 알림이 없습니다."(시안 동일). 설정 톱니 → 설정. 전원/Esc(로비) → 종료 확인 팝업(취소·종료).
- 파티 칸 "+ 초대" → 초대 코드 `CH-7K2Q`를 클립보드에 복사하고 토스트(시안 문구 그대로, 코드는 시안 자리표시).
- 로비 맵 창 클릭 → 모드 선택 창(솔로/스쿼드·시점 전환이 로비에 즉시 반영, 확인/Esc로 닫기).
- 커스텀 모드: 방 만들기 → 방 생성(기존 호스트 방), 참가하기 → 입력한 주소로 참가(초대 코드 칸에 `IP:포트`를 넣는다).
- 스쿼드 상태에서 시작 → 토스트 "스쿼드 매치는 팀 규칙 병합 뒤에 열립니다."(미구현을 숨기지 않음).

## 시안과 다른 점 / 아직 안 된 것
1. 글꼴 굵기(600/800 → Bold), 게임 이름 `[게임 이름]` → SUBLEVEL, 버전 문구 `v0.1.0-dev · 자리표시 화면` → 실제 `v`+버전.
2. 모달 카드의 배경 블러(backdrop-filter)는 없어 카드를 거의 불투명하게 그림.
3. 커스텀 모드의 최대 인원·봇 채우기·오염 속도·시점 값은 화면에서만 바뀌고 방에는 아직 전달되지 않음. 초대 "코드"는 아직 서버 코드가 아니라 호스트 주소(IP:포트).
4. 방 안 화면(`LobbyScreen` Room 뷰)은 시안에 없어 이전 중앙 패널 그대로.
5. 크레딧 표는 시안에 있는 CC0 행(Poly Haven 등)을 넣지 않음(`Credits.Entries`는 CC BY 전용, 공통 파일이라 이 트랙에서 안 바꿈). 표는 마우스 휠로 스크롤, 스크롤바 없음.
6. 외형 탭은 아직 토스트 "다음 작업에서 열립니다"만 함(화면 미구현), 설정·결과·훈련장 진입은 시안 대조 전(JSON 내보내기 `char/result/tutorial`까지만 완료).
