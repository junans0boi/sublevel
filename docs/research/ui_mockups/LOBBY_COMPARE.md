# 로비 시안 ↔ 구현 1:1 대조 (2026-11-16)

기준: `adopted.html`의 "로비 · 스쿼드 대기"(②승강기 조작반 + B 다크). 시안은 브라우저에서 1920×1080 무대 좌표로 측정(`lobby_mock_measures.txt`: 요소 클래스·텍스트·x,y,w,h·배경·글자색·글자 크기/굵기). 구현은 Unity에서 같은 상태를 렌더하고 모든 UI 요소의 무대 좌표를 덤프(`lobby_impl_rects.txt`, 텍스트는 글자 상자 기준). 나란히 보기: `lobby_compare.html`(시안 라이브 + 구현 PNG).

캡처(구현): `docs/bible/img/ui/lobby_{solo,squad,search,member}_1920x1080.png`, 스쿼드 상태 `lobby_squad_{2560x1440,1366x768,1920x1200,3440x1440}.png`. 전체 세트(5해상도 × 로비 4상태·커스텀·설정·크레딧)는 `Logs/uishots/`(`UiCaptureTests`로 재생성).

## 구현 방식
- 무대 1920×1080 컨테이너(`StageFit`): 캔버스가 더 좁으면(16:10) 축소·상하 여백, 더 넓으면(21:9) 가운데 정렬. 배경 장면은 무대 안에 있어 항상 UI와 같이 움직인다.
- 시안의 SVG 장면(홀 배경·승강기 문·바닥 격자)과 아이콘 8종은 시안에서 PNG로 변환해 사용(`Resources/Ui`, ASSET_LEDGER U-0001). 승강장 타일·인물·모든 버튼·글자는 코드(uGUI)로 시안 좌표에 직접 배치.

## 남은 차이 (모두 의도·한계, 숨김 없음)
1. **글꼴·굵기**: 시안은 600/800 굵기, Noto Sans KR 한 벌만 있어 Bold로 대체(굵기 단계 3→1). 글자 폭이 달라 일부 줄바꿈 차이: 열쇠 안내 본문은 18px→16px로 줄여 2줄 유지(시안 2줄).
2. **게임 이름**: 시안 자리표시 "[게임 이름]" → 확정명 "SUBLEVEL". 로고 아이콘은 시안의 자리표시 그대로.
3. **외형·알림**: 탭 "외형"과 알림 버튼은 화면이 아직 없어 누르면 동작 없음(시안엔 화면 있음).
4. **스쿼드 시작**: 팀 규칙 병합 전이라 스쿼드로 시작하지 못함(솔로만 시작). 시안의 파티원 합류·초대 코드 복사·모드 선택 창(맵 창 클릭)은 미구현, 초대 버튼은 모양만.
5. **서아·도윤 샘플 파티**: 캡처는 시안과 같은 비교를 위해 코드로 파티를 구성한 것(실제 게임 시작 상태는 솔로 1인).
6. **버전 표시** `v1.0`: 시안에 없는 기존 표시(왼쪽 아래로 옮김).
7. **그림자·블러**: 시안 콘솔의 위쪽 그림자와 패널의 안쪽 하이라이트, 인물 그림자 타원은 생략.
8. **로고 바**·핑 칩은 고정 값(18 ms) 자리표시 그대로.
