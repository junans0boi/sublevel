# 17. T8 남은 건물 종류와 마을 배치 설계 (S1, #249, 2026-11-16, 초안)

상태: 상가·빌라·아파트 생성기(`t8_Buildings.Tall.cs.txt`)와 마을 배치(`t8_TownLayout.cs.txt`)는 순수 C#으로 작성·검증(.NET 스크래치), Assets 미반영(Unity 순번 대기). 나머지 5종은 설계만.

## 마을 배치 `TownLayout.Place` (구현·검증됨)
- 한 마을 = 대로 1개(가로 직선, 폭 12/8/6 m) + 양쪽 앞줄 + 뒷골목(3.2 m) 뒤의 뒷줄 + 2~5채마다 가로지르는 골목(3.2 m). 상가·노점은 줄집(틈 0.4 m), 나머지 3 m.
- 상가·주택·빌라·노점은 대로 쪽, 학교·시장·아파트·막사·공장·창고·감시탑·헛간은 뒷줄. 양쪽 균형(줄마다 짧은 쪽에 배정).
- 결과: 청람읍(440×300 m, 90채: 상가 36·주택 21·노점 8·빌라 6·아파트 4·막사 4·학교 3·감시탑 2·공장 2·창고 2·헛간 1·시장 1) 4개 시드 모두 90/90 배치, 겹침 0, 상자 밖 0, 모든 건물 정면이 대로나 뒷골목에 닿음. 중형(190×130, 16채)·소촌(160×50, 6채)도 전부 배치.
- 한계: 직선 대로 하나라 "블록 16칸" 같은 격자 도심은 아니다(청람읍 시안은 중앙로 12 m + 뒷골목 3 m). 학교 운동장·시장 광장·막사 울타리 같은 마을별 고유 구조물은 다음 단계. 도로 그래프(RoadGraph)의 마을 접점과 대로 방향 정렬은 T9.

## 남은 종류 생성기 설계 (기존 5모양 위임 중, 전용 생성기 필요)
| 종류 | 설계 | 재사용 | 열린 점 |
|---|---|---|---|
| 학교(2~3층) | 긴 건물(폭 24~34×깊이 11~13), 가운데 복도 + 양쪽 교실 6~8개/층, 양 끝 계단 2곳(층마다 직선 계단), 앞 운동장은 마을 배치의 빈터 | Block의 층·계단·옥상 규칙, Warehouse 복도 | 교실이 많아 조각·가구 예산(교실 가구 3종만), 1층 현관 문 2개 |
| 막사(1~2층) | 함석 지붕 긴 홀 + 침상 줄(Bed 8~12), 무기고 방 1개(창 없음, 루팅 상급), 경비실 | Warehouse(홀) + Furnish(침상) | 무기고는 `RoomWithoutWindow` 예외 |
| 시장(1층) | 열린 지붕 홀 + 가판 줄(Counter/Crate), 문 대신 열린 면 2개 | Warehouse | 열린 면의 벽 없음 → BuildingRules "닫힌 건물" 가정 예외 |
| 노점(1층) | 2×3 m 지붕+카운터, 벽 없음 | Shed | 진입 불가로 센다(towns.json), 충돌체만 |
| 감시탑(1~2층) | 5×5 m 콘크리트 기둥 + 위 상자 방 + 사다리 대신 직선 계단, 난간 데크 | Block 계단 | 사다리 없음, 시야 창 |
공통: 새 종류는 `BuildingKinds.Family` 위임을 전용 생성기로 바꿀 때 `FootprintLimits`·`MaxPieces/MaxDecor`·`SurfaceFor`를 같이 갱신한다. 순서 제안: 학교 → 막사 → 감시탑 → 시장 → 노점(작은 것은 마지막).
