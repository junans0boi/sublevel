# B1 감지 급증 제거 측정 (#370, 2026-11-17)

같은 서버 빌드·같은 머신·같은 월드에서 임시 환경변수로 옛 동작(legacy: 선형 스캔·동기 위상)과 새 동작을 번갈아 실행. `--perf p0|p3 --participants 80 --bots 79 --region C`, 10 s 창 평균(첫 창들 제외). 임시 스위치는 제거했다. 값은 프레임당 ms, `평균 / p99`.

| 조건 | 봇 AI | 감지 | 아이템 감지 | 문 검사 | 서버 프레임 평균 / p99 |
|---|---|---|---|---|---|
| p0 legacy | 3.49 / 26.99 | 2.11 / 21.33 | 1.92 / 19.34 | 0.63 / 14.12 | 10.85 / 35.0 |
| p0 새(경로 위상·예산 포함) | 0.85 / 3.89 | 0.21 / 2.01 | 0.09 / 0.87 | 0.003 / 0.05 | 8.21 / 12.2 |
| p3(79봇 밀집) legacy | 3.53 / 24.04 | 1.87 / 18.78 | 1.64 / 16.26 | 0.54 / 14.14 | 10.36 / 31.6 |
| p3 새 | 1.35 / 4.93 | 0.18 / 2.22 | 0.03 / 0.72 | 0.003 / 0.06 | 8.57 / 12.6 |
| p3 무장(소총+탄 200, 교전 창) legacy | 0.77 / 7.39 (창 100 s) | | | | p99 25.9 (창 90 s) / 14.2 |
| p3 무장 새 | 0.35 / 3.97 | | | | p99 18.0 / 12.1 |

- 이 머신은 스파이크 때보다 부하가 높아 legacy가 더 나쁘다(스파이크 평균 1.5 / p99 12.1). 비율로 본다: 봇 AI p99 약 1/7.
- 단계별: 위상·해시만(경로 지터·예산 전) p0 봇 AI p99 6.75 → 경로 계산 몰림(p99 3.8 ms)이 남아 경로 간격 ±20% 지터 + 프레임당 계획 2회 예산 추가 → 3.89.
- p3 밀집은 봇 AI p99 4.93으로 ≤4 ms 목표를 약간 넘는다(목표 조건은 배회 p0). 서버 프레임 p99 ≤ 25 ms는 모든 창에서 충족(최대 18.0, legacy 무장 창 25.9로 스파이크 재현).
- 한계: 각 조건 1회 실행(분산 없음), 무장 교전 창은 25초 안에 봇이 몰살되는 스파이크와 같은 제약으로 창 2개만.
