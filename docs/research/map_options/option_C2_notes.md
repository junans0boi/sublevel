# 맵 안 C2 · 청람도 (강 + 산악, 50인) 설계 메모

보기: `option_C2_river_mountain.html` (자체 완결, 외부 라이브러리 없음, 시드 고정 노이즈로 지형 생성).
C안의 구조(강이 섬을 가르고 다리가 병목)를 유지하고 산악 지형, 연결 도로망, 50인 규모를 더했다. 조사·설계 단계이며 코드/에셋은 건드리지 않았다.

## 설계 이유
- 도시 밀도: 수도급 청람읍을 440 x 300 m에 90채로 압축해 블록·골목·상가 줄이 있는 시가전을 만든다. 나머지 마을은 지형 단위로 흩어 파밍 동선을 만든다.
- 강: 경계이자 병목. 다리 4(청람교, 북강교, 하구교, 동천교, 발원교 포함 5) + 얕은 여울 우회. 강변 제방 때문에 수변 엄폐가 낮아 교전이 다리 앞에 몰린다.
- 산: 산악은 길(고개)로만 차량 통행. 안부는 능선 높이를 80% 낮춰 도로가 지나가게 하고, 다른 안부는 보행 전용으로 남겨 우회로를 만든다.
- 구현 시사점(생성기): 강 곡선과 하상 고도, 능선 폴리라인과 안부 가중, 도로 절토(경사 11도), 블록 생성기, 지역 6개와 승강장 20곳의 규칙 파라미터화(MinElevators/Max, LotRange)가 필요하다. 411채는 PERF_BUDGET(드로우콜 2,500)에 비해 크므로 지역 단위 스트리밍/배칭 측정이 선행되어야 한다.
