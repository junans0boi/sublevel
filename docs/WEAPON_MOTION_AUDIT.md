# 무기 사용 중 움직임 감사 (WEAPON_MOTION_AUDIT)

2026-11-23 · 준환 보고 "무기 이용간 움직임이 자연스럽지 않다" · 기준: PUBG류 3인칭/1인칭 슈터.

## 방법

- 도구: `Tests/PlayMode/WeaponMotionCaptureTests.cs` (Explicit). `Time.captureFramerate = 60` 고정 프레임으로 매 프레임 측정 → `frames.csv`, 몇 프레임마다 JPG(게임 카메라 + 앞-오른쪽 사선 카메라, 1인칭은 게임 카메라만).
  - 재현: `WM_SHOTS=Logs/wm_before WM_ONLY=rifle,smg,pistol,shotgun,sniper,other tools/unity.sh test playmode Game.Tests.WeaponMotionCaptureTests`
  - 사진은 소총·권총만(`WM_SHOTS_ALL=1`이면 전부). 수치는 5종 전부.
- 무기: 소총(3)·SMG(2)·권총(1)·샷건(4)·저격(5) + 근접(21)·투척·붕대.
- 장면(3인칭): 정지, 8방향 달리기, 8방향 조준(어깨) 걷기, 느린 걷기, 질주, 질주→조준, 조준→질주, 힙→조준(정지), 조준 중 앉기↔서기, 앉아 걷기 앞/옆, 제자리 회전(힙·조준), 힙 사격, 조준경 사격, 장전(정지·걷기), 점프(정지·달리기), 무기 교체(나가기·돌아오기), 엎드려 포복. 1인칭: 정지, 달리기 앞/옆, 질주, 질주→조준, 조준 걷기, 힙·조준경 사격, 장전, 달리기 점프, 교체.
- 측정 열: `palm`(왼손바닥↔총 LeftHandGrip, 붙어 있으면 0.030), `muzzleDegS`(캐릭터 기준 총구 각속도), `handMS`(캐릭터 기준 오른손 속도 — 한 프레임 튐 감지), `headGap`/`chestGap`(총 축과 머리/가슴 사이 여유, 음수=관통 후보), `footSlide`(낮은 발이 땅에 있을 때 수평 속도), `shoulderYaw`/`hipsYaw`, `fpJerk`(1인칭 총의 카메라 공간 가속도 m/s²).
- 증거: `Logs/wm_before/`(수정 전, 4,697장 + frames.csv), `Logs/wm_after/`(수정 후). 요약 스크립트는 공유 노트 폴더의 `weapon-motion.md` 참조.
- 주의: 1인칭에서는 총이 눈 앞으로 옮겨지므로 `muzzleDegS`/`aimErr`가 3인칭 몸 기준으로 계산돼 무의미한 값(권총 질주 10707°/s)이 나온다 → 1인칭은 `fpJerk`만 본다. 3인칭 조준경(Sights)도 총이 눈 앞이라 `palm` 0.32는 측정 착시.

### 문제 아님 / 잘 되는 것

- **두 손 IK(서서)**: 소총·SMG·샷건·저격·권총 모두 걷기·달리기·질주·조준·회전·점프에서 palm 0.030 유지(손이 총에서 안 떨어짐).
- **조준 정확도**: 어깨 조준 후 aimErr 0.0°(3인칭), 1인칭 조준 걷기 3.9°(bob).
- **총이 머리/몸 관통**: headGap 최저 -0.07 m는 어깨 조준 때 개머리판이 뺨에 붙는 정상 자세(사진 확인). 낮은 준비 자세 chestGap -0.03 m는 총이 가슴 앞을 지나는 정도로 관통 아님.
- **상체가 조준 방향 유지**: 8방향 모두 shoulderYaw가 홀드 비틀기(낮은 준비 10~11°, 조준 25°) 그대로, 다리(hipsYaw)는 이동 방향 쪽(옆 60°, 대각 45°).
- **장전**: SMG·권총은 Action 레이어 클립으로 왼손이 탄창으로 감(palm 최대 0.57 m는 의도). 소총은 수정 전 캡처에서 탄창이 가득 차 장전이 안 일어남 → 수정 후 캡처에 사격 후 장전으로 보강.
- **사격 반동**: 3인칭 kick 0.12 s, 1인칭 jerk 120~130은 반동 자체(의도된 날카로움).

### 측정 안 한 것

- 위·아래 조준(look pitch)에서 머리·척추 추종: 이번 스크립트는 pitch 0만 찍음. 코드상 서서는 머리가 피치를 따로 따라가지 않음(가슴이 40%만) → #490.
- 소총 장전: 캡처 스크립트가 쏜 뒤 장전하도록 고쳤지만 소총은 수정 후에도 ReloadProgress -1(장전 미발생, 원인 미확인). 장전 판정은 SMG·권총 데이터로 함.
- 원격 플레이어 시점(복제 지연 포함), 차량·수영·난간.
