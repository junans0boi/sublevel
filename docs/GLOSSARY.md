# GLOSSARY — 용어집 (스킬 grilling/wayfinder 등이 참조)

| 용어 | 정의 |
|---|---|
| 구역(Zone) | 시설 내 독립된 지역(A~F, 코어). 폐쇄 단위 |
| 서브존 | 구역 내 부분 폐쇄 모듈 |
| 봉쇄(Lockdown) | 구역 출입 차단 상태. 내부는 방사능 데미지 |
| 레드존 폭격 | 구역 단위 미사일 낙하 단계 |
| 폐쇄(Closed) | 진입 불가 최종 상태 |
| 열쇠 | 봉쇄 구역 문을 여는 아이템. 열린 문은 10초 유지 |
| 출구 | 봉쇄 구역당 정확히 1개의 탈출구(매 판 랜덤) |
| 힌트 1/2단계 | 경고 때 대략 반경 / 근접 시 비콘·사이렌 |
| 칩 | 사망 시 드롭, 팀원 부활용 (팀 모드) |
| 칩 보관함 | 구역 입구의 칩 수거 장소(사망 후 90초) |
| 엘리베이터 | 투입 및 구역 간 이동 수단(구역당 3~4대) |
| 수렴 지점 | 구역 내 교전이 모이는 거점(3~4개) |
| 스폰 보호 | 투입 후 5~10초 무적 |
| 서버 권위 | 상태 결정은 서버(싱글=호스트) |
| 타이틀 | 로드맵의 기능 단위 1개 = 루프 1회 |
| 지도(Map) | wayfinder 지도 이슈(`wayfinder:map`) |
| DoD | Definition of Done |
| 시드 | 매치 랜덤 재현용 값 |
| 스모크 | 기능이 끝에서 끝까지 최소한으로 동작함을 확인하는 자동 테스트 |
| 픽스처 | 테스트 전용 프리팹·데이터. 게임 콘텐츠가 아니며 릴리스에 포함하지 않음 |
| 복제(Replication) | 서버의 상태가 클라이언트 사본에 전달되는 것 |
| 전투원(Combatant) | 쏘고 맞을 수 있는 개체. 플레이어·훈련용 더미·(M2) 봇 |
| 훈련용 더미 | M1 한정 교전 상대. 제자리에서 보이는 플레이어를 사격. 봇이 아님 |
| 소지품(Loadout) | 전투원이 가진 무기 슬롯 2칸·예비 탄약·회복 키트 |
| 회복 키트 | 사용 시 체력을 회복하는 소모품 |
| 루팅 지점 | 매치 시작 때 아이템이 놓이는 위치. 내용물은 시드로 결정 |
| 테스트 박스 | M1 검증용 임시 맵(60x60, 기본 도형) |
| 호스트 | 서버와 클라이언트를 한 프로세스에서 함께 돌리는 실행 형태(싱글플레이) |
