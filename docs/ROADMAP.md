# ROADMAP — 마일스톤과 게이트

원칙: 각 마일스톤은 **게이트**를 통과해야 다음으로. 각 마일스톤 안의 타이틀마다 WORKFLOW 루프를 돈다. 무거운 작업은 순차.

|---|---|---|---|

## M0 세부 티켓 후보
1. unity.sh + 프로젝트 생성 + URP/패키지
2. 테스트 프레임워크 + CI 스크립트
3. BuildScript mac/win
4. 헤드리스 씬 생성 PoC (SceneBuilder)
5. 프레임타임/스크린샷 캡처 PoC
6. Fish-Net 호스트+클라 스모크
7. 에셋 임포트 파이프라인(KTX2, LOD) + ASSET_LEDGER 자동 검증 스크립트
8. PERF_BUDGET 측정·확정

## M1.6 타이틀 (ADR-043)
| 타이틀 | 내용 | 완료 조건 |
|---|---|---|
| M1.6a 조준·이동 감각 | 재실행 시 이어지는 문제 수정, 우클릭 꾹=견착·탭=조준 토글(이동 속도·반동·FOV), Q/E 기울이기, 8방향 이동 블렌드와 발 닿는 시점 발소리, 상체 레이어 분리 | 자동 테스트 통과, mac 빌드 예산 내, 사람 확인 항목 목록 |
| M1.6b 전투 피드백 | 총구 화염·탄 궤적·탄착·피격 표시 등 맞추는 느낌 | (타이틀 시작 때 정함) |
| M1.6c 기본 UI | 텍스트 HUD를 게임 HUD로, 탭 인벤토리, 종료 메뉴 | (타이틀 시작 때 정함) |

순서는 M1.6a → M1.6b → M1.6c → M2-2. 타이틀이 끝날 때마다 멈추고 보고한다.

## M2 타이틀 (ADR-039)
| 타이틀 | 내용 | 완료 조건 |
|---|---|---|
| M2-1 구역 D 블록아웃 | 기본 도형으로 공장 레이아웃을 코드 생성. 수렴 지점 3~4곳, 엘리베이터 3~4곳 위치, 내비메시 | 레이아웃 규칙·내비메시 연결성 헤드리스 테스트 통과, mac 빌드 성능 예산 내. 외부 에셋 없음 |
| M2-2 봇 AI | 서버측 봇(이동·교전·루팅), 훈련용 더미 대체 | 봇이 내비메시로 이동해 교전하는 자동 테스트 통과 |
| M2-3 엘리베이터 투입 | 엘리베이터로 구역에 투입, 스폰 보호, 시작 인원 상한 | 플레이어·봇이 엘리베이터에서 시작하는 자동 테스트 통과 |
| M2-4 구역 D 외형 | 블록아웃을 승인된 룩(M1.5)과 CC0 에셋으로 교체 | 대장 검증 통과, 예산 내, 사용자 룩 승인 |

순서는 M2-1(완료) → **M1.6** → M2-2 → M2-3 → M2-4. 타이틀마다 WORKFLOW 루프 1회, 타이틀이 끝나면 멈추고 보고한다.

## 우선순위 변경 규칙
M1~M5 순서는 바꾸지 않는다(M1.5는 사용자 지시로 M1과 M2 사이에 추가, ADR-035. M1.6은 사용자 지시로 M2-1과 M2-2 사이에 추가, ADR-043). 기능을 더 넣고 싶으면 ADR로 근거 + 예산 영향 기록.
