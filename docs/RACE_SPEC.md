# 대기 섬 자동차 경주 스펙 (3차, #423)

상태: 진행 결정(준환 2026-11-20 "아니, 구현하자"). 결정은 ADR-505~511(가정). 대기 섬 본 스펙은 `docs/WAITING_ISLAND_SPEC.md`.
이슈: 지도·스펙·티켓 번호는 `docs/PROGRESS.md` 또는 지도 이슈 참조.

## Problem Statement
대기 섬에서 할 수 있는 건 번지·사격·구경이 전부라, 차를 좋아하는 플레이어는 판 시작 전 시간을 쓸 곳이 없다. 섬은 지름 80m에 사람·시설이 가득해 차를 몰 공간도 없다.

## Solution
섬 동쪽 벽에 문을 내고 그 너머에 밀폐된 **경주장**을 붙이고, 그 안에 실제 서킷처럼 꾸민 오리지널 코스(헤어핀·S자·고속 코너·시케인, 한 바퀴 약 543m, 약 35초)를 깐다. 문 안쪽 **피트**에 경주차 5대가 서 있고, 아무나 빈 차에 타서 코스를 돌며 랩 시간을 잰다(연속 타임어택). 방에서 가장 빠른 랩 3개가 큰 전광판에 번갈아 뜬다. 사람은 다치거나 치이지 않고, 차는 부서지지 않는다. 출발 신호가 오면 모두 내려 기존처럼 엘리베이터로 간다.

## User Stories
1. 대기 중인 플레이어로서, 섬에서 경주장으로 걸어 들어가고 싶다, 그래야 차를 몰 수 있다.
2. 플레이어로서, 피트에 서 있는 빈 경주차에 F로 타고 싶다, 그래야 본 판과 같은 조작으로 바로 달린다.
3. 플레이어로서, 출발선을 넘는 순간부터 랩 시간이 재지길 원한다, 그래야 따로 준비할 필요가 없다.
4. 플레이어로서, 운전 중 화면에 지금 랩·직전 랩·내 최고 랩이 보이길 원한다, 그래야 기록을 줄여 나간다.
5. 플레이어로서, 방에서 가장 빠른 3명이 큰 전광판에 뜨길 원한다, 그래야 서로 겨룬다.
6. 플레이어로서, 벽에 부딪혀도 차가 부서지거나 내 몸이 튕겨 나가지 않길 원한다, 그래야 마음껏 달린다.
7. 플레이어로서, 연료 걱정 없이 달리고 싶다.
8. 걷는 플레이어로서, 차에 치이거나 밀려 밖으로 나가지 않길 원한다.
9. 걷는 플레이어로서, 코스 위로 걸어 들어갈 수 없길 원한다, 그래야 남의 기록을 방해하지 않는다.
10. 플레이어로서, 차가 섬 안으로 들어오지 않길 원한다.
11. 플레이어로서, 누가 버린 차가 코스 위에 뒤집혀 있지 않길 원한다(빈 차는 피트로 돌아감).
12. 플레이어로서, 역주행이나 순간이동으로 만든 기록이 인정되지 않길 원한다.
13. 플레이어로서, 출발 신호가 오면 경주 중이어도 엘리베이터로 정상 이동하길 원한다.
14. 플레이어로서, 다른 사람이 달리는 차가 끊김 없이 보이길 원한다.
15. 늦게 들어온 플레이어로서, 이미 세워진 TOP3와 달리는 차를 그대로 보고 싶다.
16. 플레이어로서, 경주장이 본 맵에서 보이지 않길 원한다(밀폐, 맵에서 1.7km 이상).
17. 플레이어로서, 섬에서 얻은 기록이 본 판에 아무 영향이 없길 원한다.
18. 개발자로서, 코스 기하·랩 판정·순위가 순수 함수라 헤드리스로 테스트되길 원한다.
19. 개발자로서, 80명 대기에서도 대역폭·서버 시간이 예산 안이길 원한다(측정으로 증명).
20. 개발자로서, 차 움직임 동기화 구조(ADR-069)를 바꾸지 않길 원한다, 그래야 본 판 차량이 그대로다.
21. 준환으로서, 봇이 경주에 끼어 사람처럼 보이는 일이 없길 원한다.

## Implementation Decisions
- **Core 순수 모듈**: `RaceTrack`(서킷 꼭짓점·반경 → 중심선 샘플, 피트·경주장 기하, 출발선 기준 거리·옆 오프셋, 보행자 허용 영역·클램프, 그리드 자리, 맵과의 거리), `RaceLap`(한 운전자의 랩 판정), `RaceRecords`(사람별 최고, TOP N), `RaceBoard`(페이지 순환, 줄 서식).
- **경주차 판정은 위치**: `Vehicle.IsRaceCar` = 경주장 안. 피해(총·폭발·충돌), 연료, 충돌 하차, 로드킬이 이 값으로 꺼진다. 서버·클라 모두 같은 답이라 통신이 늘지 않는다.
- **서버 경주 진행(Net)**: 대기 방이 열릴 때 경주장이 있는 씬이면 경주차 5대를 그리드에 스폰(본 판 차량 프리팹 중 승용차 종류), 매 프레임 운전자별 `RaceLap` 갱신, 기록 제출, 빈 차 복귀, 경주장 이탈 차 복구. 출발 신호 때 하차→디스폰.
- **보행자 클램프**: 대기 중 서버 이동 감시가 섬 원 대신 `RaceTrack.ClampWalker`를 쓰고, 좌석에 앉은 사람은 건너뛴다.
- **통신**: `RaceBroadcast`(TOP3 이름 3·시간 3, 받는 사람의 진행 중 랩 경과·직전 랩·최고 랩), 서버가 연결마다 0.5초 간격 unreliable. `LobbyNet.Protocol` 7.
- **표시**: 전광판에 LAP TOP3 페이지(6초 간격, 기록 있을 때만), 운전 중 HUD 한 줄. #422 순환이 들어오면 한 페이지로 합침.
- **지오메트리**: `WorldBuilder`에 경주장(바닥·벽·지붕·노면·흰 선·연석·잔디/자갈 런오프·방호벽·타이어 벽·신호등 갠트리·그리드 칸·관중석·제동 표지판·볼라드·조명) 프로시저럴 박스·원기둥, 기존 공용 재질만. 섬 벽은 문 자리 3구간을 비운다. 새 에셋 없음.

## Testing Decisions
- 좋은 테스트 = 밖에서 보이는 결과만(랩 시간, 무효 판정, 클램프된 위치, 순위, 차 체력, 하차 후 위치).
- EditMode: `RaceTrackTests`(기하·클램프·그리드·랩·기록·전광판).
- PlayMode(World, 대기 방 강제): 경주차 5대 스폰·무적·빈 차 복귀·보행자 클램프·출발 신호 처리, 2클라이언트(원격 운전자의 랩이 서버에서 재지고 다른 클라이언트 전광판에 뜸). 선례: `WaitingIslandPlayTests`, `ReplicationVehicleTests`, `MultiHarness`.
- 비용: `RaceSyncCostTests`(대역폭, 이미 측정), 서버 시간은 독점 창에서 측정. 렌더는 섬·경주장 시점 `RenderProbe`(A 예산).
- 캡처: 경주장 조감, 그리드, 갠트리, 헤어핀·S자·시케인, 관중석, 주행 중, 전광판 TOP3 — 직접 엄격히 판정.

## Out of Scope
- 봇 운전(ADR-175), 동시 출발 레이스·대기열·순위 경기, 기록 저장·랭킹·보상, 차 움직임의 서버 권위화, 새 차종·전용 경주 모델, 정식 차량 소리(S5), 오토바이 경주.

- 경주장 밖 1.7km 바다·안개는 섬과 같은 방식(ADR-381).
