## 타이틀별 직접 확인 목록 예시(M1.6b)
1. 사격 시 총구 화염과 탄도선이 눈에 보이는가(조준/허리 사격, TPP/FPP).
2. 콘크리트/금속에 맞았을 때 서로 다른 임팩트가 보이는가.
3. 적(더미)에 맞았을 때 히트마커와 소리가 즉시 나는가, 킬 때 다르게 나는가.
4. 맞았다는 것을 크로스헤어만 보고 알 수 있는가.
5. 무기별로 반동 느낌이 구분되는가.
6. 프레임이 떨어지지 않는가(연속 사격 중).
