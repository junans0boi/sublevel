# UI_SPEC — HUD, 인벤토리, 메뉴 기준 (M1.6c 핵심, 디자인 완성도는 M5)

목표 수준: **"좌하단 텍스트"에서 벗어나 게임처럼 읽히는 기능적 UI.** 시각적 완성도(애니메이션, 아이콘 세트의 통일감, 효과)는 M5에서 다듬는다. 톤은 어두운 산업 시설, 절제된 색, 유치하지 않게(둥근 장난감 느낌 금지). 모든 요소는 해상도에 대응한다(Canvas Scaler 기준 1920x1080).

## 1. 인게임 HUD
| 위치 | 요소 |
|---|---|
| 하단 중앙 | 체력 막대(수치 보조), 회복 중이면 표시 |
| 우하단 | 현재 무기 이름·아이콘, 장탄/예비 탄약, 사격 모드(있다면), 무기 슬롯 1·2(선택 강조) |
| 하단 좌 | 소모품(의료키트 수와 단축키), 방어구가 생기면 표시 |
| 상단 중앙 | 나침반(방향), 구역 상태 타이머(경고/봉쇄/폭격 카운트다운)는 M3 연동 자리 확보 |
| 중앙 | 크로스헤어(탄퍼짐 반영, 조준 시 변화), 히트마커 |
| 화면 가장자리 | 피격 방향 표시, 저체력 비네트 |
| 상단 우측 | 생존자 수/킬 수(자리만, 값은 M2~M3) |
| 좌측 | 킬 피드(자리만) |
| 하단 보조 | 줍기 프롬프트(아이템 이름 + 키), 재장전 중 표시 |
- 글꼴: **SIL OFL 또는 CC0만**. 한글 지원 폰트 사용(예: Noto Sans KR 등, 라이선스 확인 후 ledger 기록). 숫자와 영문 가독성 우선.
- 아이콘: CC0만(또는 직접 제작). CC-BY는 크레딧 화면 필요. 출처 불명 금지.
- 구현: uGUI 또는 UI Toolkit 중 세션이 선택(ADR). 서버가 값을 결정하고 UI는 표시만.

## 2. Tab 인벤토리 (PT-3: "무슨 아이템을 가졌는지 모름")
- Tab으로 열고 닫기. 열리는 동안 카메라/사격 입력 정지(마우스 커서 표시).
- 배그식 3열: **장비 슬롯(무기 1·2, 방어구/헬멧 자리), 소지품 목록(탄약 종류별 수, 의료키트, 투척물, 열쇠·칩 자리), 주변 바닥 아이템 목록**.
- 최소 기능: 보기, 바닥 아이템 줍기(클릭), 아이템 버리기, 무기 교체. 드래그&드롭은 후순위(클릭으로 충분).
- 데이터는 서버 권위 인벤토리 상태를 그대로 표시.

## 3. Esc 메뉴 (PT-3: "Esc 누르면 그냥 꺼짐")
- Esc = 일시정지 메뉴(싱글에서는 게임 일시정지 가능, 멀티 전환 시에는 정지 없음 → 이 차이를 구조에 반영).
- 항목: **계속하기 / 처음부터(새 매치 재시작) / 설정 / 메인 메뉴 / 종료**. 종료는 확인 없이 즉시.
- 설정 최소: 마우스 감도(조준 감도 별도), 볼륨(마스터/효과/환경), 그래픽 프리셋(SSAO 끄기 포함), 시점 기본값, 키 안내(키 바인딩 변경은 후순위).
- 재시작은 새 매치(시드 포함). 앞서 고친 "이어서 시작" 버그가 재발하지 않게 테스트 유지.

## 4. 메인 메뉴 (간단)
시작(솔로, 이후 팀), 설정, 종료. 게임 이름이 정해지면 타이틀 표시. 현재 TestBox/ZoneD 씬 선택은 개발 전용 메뉴로 분리하거나 커맨드라인 인자로.

## 5. 입력 안내
첫 실행 시 간단한 조작 안내(키 목록)를 Esc 메뉴 또는 시작 시 표시. 현재 PROGRESS.md의 조작법을 UI로 옮긴다.

## 6. 접근성/가독성
- 최소 글자 크기 기준 정의(1080p에서 본문 ≥ 18px 상당).
- 중요한 정보(구역 경고, 피격)는 소리 + 시각 동시.
- 색만으로 구분하지 않는다.

## 7. 완료 판정
스크린샷을 뽑아 세션이 직접 열어 가독성 점검(1080p, 1440p 두 장) + 준환 직접 확인 목록. HUD가 "텍스트 덩어리"가 아니라 영역별로 분리되어 보여야 한다.
