# 오염 시스템 (최종 지역)

> 상태: 제안 · 요약: 자기장 대신 방사능 오염(하이브리드, 2026-11-16 확정): 지역 단위로 오염을 확정하고 전선이 지형을 따라 도심 방향으로 퍼진다. 전선이 지나간 지역은 계속 위험하며, 지역 간 탈출은 열쇠로 여는 엘리베이터(1회용, 비오염 지역으로만). 세부 수치는 시뮬레이션 후 조정.

## 정의

섬은 6개 지역으로 나뉜다(강·능선 기준). 시간이 지나면 지역이 하나씩 '오염 확정'되고, 확정된 지역에서는 오염 전선이 안쪽(도심 방향)으로 퍼지며 전선 뒤는 통행 불가에 가까운 위험지대가 된다. 마지막에 남는 지역이 최종 지역이다.

근거: 준환의 선택 'C 하이브리드'. 지금 구현은 'SPEC §3 지역 순차 봉쇄'(지역 4개, 엘리베이터 3~4대/지역)이며 규칙이 애매하다고 판단돼 이 문서로 확정한다. 규칙 변경이므로 ADR 필수(CLAUDE.md 규칙 5).

준환의 결정(2026-11-16): ① 물리 차단은 없다. 오염은 '전선'이 퍼지며 일으키고, 전선이 지나간 지역 전체가 계속 위험하다(전선은 그 경계). ② 지역 간 이동(탈출)은 '열쇠로 여는 엘리베이터'로만 가능하다. 열쇠는 1회용이며 비오염 지역으로만 이동한다. ③ 최종 지역은 6개 중 무작위(육로 연결 보장). ④ 판 길이 20~25분. ⑤ 데미지는 단계가 갈수록 증가. ⑥ 예고는 사이렌+방송+지도 점멸 90~120초 전. ⑦ 방독 아이템은 소모성으로 전선을 짧게 통과 가능(최종 지역에서는 무효).

열쇠 엘리베이터 규칙(2026-11-16): 열쇠는 희귀 파밍 + 보급상자에서 판당 약 6~8개. 팀원 중 열쇠를 가진 한 명이 승강장에서 사용하면 팀원이 함께 탑승할 수 있다(열쇠 1개 소모). 목적지는 본인이 선택한 비오염 지역의 승강장. 전선이 닥친 지역의 승강장도 작동하지만, 한 번 쓰면 '전력 충전' 시간 동안 사용할 수 없고 충전되면 다시 쓸 수 있다.

전선·시간표 확정(2026-11-16): 위 단계표와 속도(평지 60 / 도로 100 / 급경사 30 m/분)를 사용. 열쇠 수(판당 6개 기준)와 팀 인원(o2)은 함께 확정해야 한다 — 7개·4인 분대면 위협 지역 인원의 절반 이상이 빠져나가 압박이 약해진다.

- 강·산 지형이 지역 경계 → 다리와 고개가 병목이 되어 '언제 건너고 어디로 빠질지' 전략이 생긴다.
- 지역 순서는 시드로 무작위 + 남은 지역이 항상 육로로 이어지는 순서만 허용(C2 시안의 '폐쇄 순서 뽑기' 방식).
- 서버가 시간·시드만으로 상태를 계산하고 클라이언트에는 '지역 상태 + 전선 위치'만 복제한다(작은 데이터).

## 열쇠 엘리베이터 (신규 기능)

엘리베이터가 투입 전용에서 '지역 탈출 수단'으로 확장된다. 열쇠(1회용)를 승강장에서 쓰면 비오염 지역의 승강장으로 이동한다. 오염 지역으로는 이동할 수 없다.

아이템 '열쇠'는 이미 코드에 존재하지만(armor_items 섹션 참조) 루팅 표에는 없고 용도가 다르다. 새 아이템 종류(예: 승강기 키)로 분리할지 기존 열쇠를 확장할지는 구현 시 결정.

사용 순서(확정): 열쇠 보유자가 엘리베이터 버튼 앞에서 열쇠 삽입 → 엘리베이터 활성화 → 문 열림 → 30초 카운트다운(팀원 탑승 완료 시 열쇠 보유자가 수동으로 문 닫기 가능) → 지역 선택(15초 안에 선택하지 못하면 무효 처리).

- 열쇠: 판당 약 6~8개(희귀 파밍 + 보급상자). 50명 중 열쇠 소유자는 소수라 탈출은 팀 전략 자원이 된다.
- 팀원 중 열쇠를 가진 한 명이 사용하면 팀원이 함께 탑승한다(열쇠 1개 소모). → ADR-055(1인 1기) 개정 필요.
- 목적지: 본인이 선택한 비오염 지역의 승강장.
- 전선이 닥친 지역의 승강장도 작동하지만 1회 사용 후 '전력 충전' 시간 동안 사용 불가.
- 도로·다리는 계속 열려 있어 걸어서/차로 탈출도 가능(전선보다 앞서야 함).
- 엘리베이터 이동 소리·연출·전력 충전 UI는 사운드·UI 파트 연동.
- 봇이 열쇠를 쓸지는 봇 파트에서 결정.
- 도착 직후 보호는 없다(매복 위험) — 도착 승강장 주변 교전을 규칙으로 허용.
- 봇은 열쇠를 줍고, 전선이 임박하면 사용한다.
- 문이 열린 30초 동안 누구나(적 포함) 탑승할 수 있다 — 적이 동승하면 도착지에서 즉시 교전. 열쇠 보유자가 문을 닫는 타이밍이 전략 요소.
- 탑승 상한 4명. 무효(지역 미선택) 시 열쇠는 돌려받고 문이 닫히며 승강장은 재충전.
- 열쇠 배치: 먼저 오염될 지역에 덜 배치(편중 0.5), 열쇠 사용 후 팀 쿨다운 3분 이상. 시뮬레이션상 7~8개 평균 이탈 약 25~28%(경계~적정)로 완화.

  - 선택지: 전선 도달 전까지 작동, 도달한 승강장은 정지 / 오염 확정 지역도 작동(마지막 탈출구) / 확정 즉시 정지  · 추천: 전선 도달 전까지 작동, 도달한 승강장은 정지
  - 근거: 탈출 수단이 있으면서도 늦으면 못 쓰는 긴장.
- [x] **전선 속도·간격(제안): 전선은 몇 m/분으로 퍼지나?** (확정) → 평지 60 m/분(도로 100, 급경사 30), 확정 시각 4/7.5/10.5/13/15/16.5분(6번째가 최종 지역), 경고 105초 전, DPS(HP100) 2/3.2/5/8/12.6/20 초당, 판 길이 평균 22.1분(20.1~24.1)

  - 근거: 청람도 3.2km²·지역 6개·20~25분에 맞춘 시뮬레이션 HTML로 확정.
- [x] **도착 지점 선택** (확정) → 내가 선택한 비오염 지역의 승강장
  - 선택지: 내가 선택한 비오염 지역의 승강장  · 추천: 내가 선택한 비오염 지역의 승강장

- [x] **한 번 타는 인원 한도와 탑승 조건은?** (확정) → 열쇠 보유자가 엘리베이터 버튼 앞에서 열쇠 삽입 → 엘리베이터 활성화 → 문 열림 → 30초 카운트다운(팀원 탑승 완료 시 열쇠 보유자가 수동으로 문 닫기 가능) → 지역 선택(15초 안에 선택하지 못하면 무효 처리)

  - 근거: 준환 결정(팀원 동승)에 따라 ADR-055(1인 1기)를 '투입용 1인 1기 / 탈출용 팀 동승'으로 나눠 개정해야 한다. 팀 최대 인원은 팀 모드 결정(o2)에 의존한다.
- [x] **전력 충전 시간은 얼마나 되나? 모든 승강장에 적용하나?** (확정) → 전선 지역 승강장만 90초 충전
  - 선택지: 전선 지역 승강장만 90초 충전 / 모든 승강장 60초 충전, 전선 지역은 120초 / 시간 고정 없이 지역마다 단계가 갈수록 길어짐  · 추천: 전선 지역 승강장만 90초 충전
  - 근거: 준환은 '전선이 닥친 지역'의 규칙으로 말했다. 충전 연출(전력 게이지, 소리)이 필요하다.
- [x] **도착 직후 보호는?** (확정) → 보호 없음(매복 위험)
  - 선택지: 도착 후 5초 무적 + 무기 사용 불가 / 보호 없음(매복 위험) / 도착 승강장 반경 안에 다른 사람이 있으면 사용 불가  · 추천: 도착 후 5초 무적 + 무기 사용 불가
  - 근거: 선택한 승강장에 매복이 생길 수 있으므로 필요. 판정은 서버.
- [x] **봇이 열쇠를 줍고 엘리베이터로 탈출하나?** (확정) → 줍고 전선이 임박하면 사용

  - 근거: 봇 대응 결정(pol_bots)과 함께 정한다.
- [x] **15초 안에 지역을 고르지 못해 '무효'가 되면 열쇠는?** (확정) → 열쇠 소모 안 됨(돌려받음), 문은 닫히고 승강장은 재충전
  - 선택지: 열쇠 소모 안 됨(돌려받음), 문은 닫히고 승강장은 재충전 / 열쇠 소모, 이동 없음 / 열쇠 소모 안 됨, 같은 승강장 즉시 재시도 가능  · 추천: 열쇠 소모 안 됨(돌려받음), 문은 닫히고 승강장은 재충전

  - 근거: 누구나 탈 수 있으면 적이 동승해 도착지에서 즉시 교전이 되어 열쇠의 가치가 낮아진다. 단, 문 앞 매복·쟁탈 재미는 줄어든다.

  - 선택지: 열쇠 위치 편중 0.5(먼저 오염될 지역에 열쇠를 덜 배치) + 팀 쿨다운(3분 이상) / 위 두 가지 + 탑승 상한 3명(확정한 4명 상한을 바꿈) / 보정 없이 6~8 그대로, 플레이테스트로 판단  · 추천: 열쇠 위치 편중 0.5(먼저 오염될 지역에 열쇠를 덜 배치) + 팀 쿨다운(3분 이상)
