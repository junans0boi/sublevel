# 맵 개요

> 상태: 제안 · 요약: 준환이 고른 방향: 청람도(맵 안 C2). 강이 섬을 가르고 산이 지역을 나누는 2.4 x 2.0 km 섬, 50명. 지금 생성기(1024 m, 지역 4, 건물 약 78채)에서 크게 바뀐다. 아래 C2 수치는 모두 제안(미승인).

## 방향

맵 안 C2(강 + 산악, 50인)가 준환이 마음에 들어 한 안이고 이제 결정된 방향이다. 단, 정확한 수치(건물 수, 마을 이름, 고개 위치 등)는 준환이 아직 승인하지 않았으므로 이 문서의 C2 수치는 전부 proposed다.

구조: 청람강이 북에서 남으로 섬을 가르고(경계이자 병목), 백운·동령·서령 3개 능선이 지역을 나눈다. 차량은 도로가 강을 건너는 다리에서만 지나가고, 산은 고개(차량 도로 스위치백)와 안부(보행)로만 넘는다. 수도급 청람읍(90채)은 440 x 300 m에 블록·골목·상가 줄로 압축한 시가전 구역이다.

구역(오염) 방식: 준환은 하이브리드를 골랐다. 지역을 하나씩 오염시키되, 오염 전선이 수도 군집(청람읍권) 쪽으로 수렴하도록 하는 방식이다. 순서는 시드로 정하되 남은 지역이 항상 육로로 이어져야 한다(MASTER_PLAN §6 C안, 페이지의 폐쇄 순서 시뮬레이션). 세부 규칙(시간표, 최종 지역 고정 여부)은 ADR이 필요하다.

- 출처: 설계 페이지 docs/research/map_options/option_C2_river_mountain.html (시드 고정 노이즈로 생성, Unity 지형 아님), 수치표 docs/research/map_options/option_C2_notes.md
- 한계: 높이·건물은 페이지의 노이즈와 평면 상자이며 Unity 지형이 아니다. 봇 길찾기·NavMesh·네트워크 부하는 검증하지 않았다.

## 구역(오염) 순서 개념: 하이브리드

준환이 하이브리드 오염 방식을 골랐다: 지역을 하나씩 오염시키되, 오염 전선이 수도 군집(청람읍권, 청람읍 도심) 쪽으로 수렴한다. 강과 산이 지역을 나누므로 다리와 고개가 병목이 되어 이동 전략이 생긴다.

규칙(제안): (1) 폐쇄 순서는 시드로 정하되 남은 지역 집합이 항상 인접 관계로 이어져 있어야 한다(페이지가 시뮬레이션으로 보여준다). (2) 서남 포구는 청람읍권 하나에만 닿으므로 그보다 먼저 닫힌다. (3) 수렴 목표를 청람읍권으로 고정할지, 시드로 정할지는 아래 결정 항목이다(SPEC §3은 최종 지역 매 판 랜덤).

이 방식은 게임 룰 변경이므로 DECISIONS.md ADR이 먼저 필요하다(CLAUDE.md 규칙 5). 오염 데미지·시간표·아이템 연동은 별도 설계 트랙이다.

## 에셋·생성 메모

- 건물: 완성된 한국 80년대/동남아 건물 CC0 에셋은 없다. 코드 생성 + 텍스처가 기본(05_map_assets §0). 종 확장(상가·아파트·학교·막사·감시탑 등)은 BuildingKind 변경이다.
- 생성기에 필요한 것(02 §4, notes): 강 곡선과 하상 고도, 능선 폴리라인과 안부, 도로 절토(11도), 블록 생성기, 지역 6개와 승강장 20곳 규칙 파라미터화(MinElevators/Max, LotRange).
- 성능: 411채는 PERF_BUDGET(드로우콜 2,500)에 비해 크다. 지역 단위 스트리밍/배칭 측정이 선행되어야 한다(06 I5).
- 이름은 전부 가상. 실제 지명·상호 금지(CLAUDE.md 규칙 1). 종교 상징은 RISKS_OPEN_QUESTIONS에 올리고 보류(MASTER_PLAN §5, 05 §H).
- 수치는 페이지 코드(시드 고정)에서 node로 추출했다. 건물 수는 시드 고정이므로 Unity 생성 결과와 다를 수 있다.
