# 개요

> 상태: 제안 · 요약: STEADY TO VIVID STUDIO의 시설 기반 배틀로얄(가칭). 오리지널 세계관, PC 전용, 판당 50명(사람+봇).

## 한 문장 정의

엘리베이터로 섬의 랜덤 지역에 투입 → 파밍 → 오염이 지역을 하나씩 삼키며 도심으로 수렴 → 마지막 지역에서 최후 1인(팀) 생존.

- 분위기: 배틀그라운드급 몰입(완전 실사는 아님). 한국 1980년대 + 열대 혼합의 가상 세계.
- 플랫폼: PC(macOS + Windows). 엔진: Unity 6.3 + URP + Fish-Net.
- 한 판: 50명(사람 + AI 봇), 약 20~25분(제안).
- 맵: 강이 가르고 산맥이 둘러싼 섬(C2안), 전 도시 차도 연결, 시가전·산악전.
- 금지: 실존 상표·총기명·차종명, 비상업 에셋, AI 생성 에셋(CLAUDE.md 규칙).
