# UI 다듬기 반복 기록 (3D가 주인공, 캡처 → 자기 비판 → 수정 ≥3회)

반복마다 `docs/bible/img/ui/iter{N}_*.png`(전/후 같은 구도)를 남긴다. 체크리스트는 anti-slop · typography · spacing · colour-palette 스킬에서 가져왔다.

## 반복 0 (착수 전 위반 목록, 37f7fd3 캡처 기준)
- **구도**: 하단 콘솔이 화면 1/3, 카드·큰 LED·50칸 막대가 장면을 압도. 인물은 화면 높이의 약 24%. → 콘솔을 150 px 막대로, 카메라를 가깝게.
- **typography**: 글자 크기 15종(14~64), 굵기는 Bold 가짜 합성. → 실제 Bold 글꼴 추가(F-0002), 크기 스케일 16/18/20/28/32로 축소.
- **colour**: 강조색(파랑)이 탭·모드·시점·상태 버튼·LED·지도에 동시에 사용. → 강조는 선택된 모드 + 상태 버튼만, 시점·LED는 중립(흰색 12%).
- **spacing**: 시안 좌표가 8px 격자가 아님(예: 742, 868, 904). → 컴팩트 막대는 8의 배수.
- **anti-slop**: 장식 테두리·그라데이션 중복(패널마다 링+그라데이션+하이라이트), 레버·50칸 막대 같은 장식 위젯. → 레버·막대·타이머 숨김, 패널은 링 1px + 약한 그라데이션만.
- **motion**: 전환 없음. → UiFx(150/200/300ms ease-out/in, 투명도·8~12px 이동만, reduced motion 존중).

(이후 반복은 Unity 창이 열린 뒤 캡처하며 채운다.)

## 반복 1 (미술감독 비평 첫 반영, 전: `before/lobby_squad_1920x1080.png` → 후: `iter1_*_after.png`)
- 위반 점검(anti-slop/typography/spacing/colour): ① 강조색 파랑·초록·분홍이 화면마다 달랐음 → 주황 하나 + 상태색(초록/빨강). ② 패널에 링+그라데이션+하이라이트 중복 → 1px 테두리 + 82% 단색, 반경 8. ③ 콘솔이 화면 1/3 → 150px 막대, 카드 2개는 한 줄. ④ 장식(레버·50칸 막대·타이머) 제거.
- 자기 비판(캡처): 인물이 화면을 넘침(너무 가까움), 팔짱 자세가 기도하는 손처럼 보임, 뒷벽이 까만 구멍, 바닥이 베이지(스폿 스프라이트 스케일 두 번 곱함).
## 반복 2 (`iter2_*`)
- 수정: 카메라를 6.2 m로(발이 막대 위에 보임), 포즈를 "뼈가 가리킬 방향" 지정 방식(`Aim`)으로 재작성, 벽 워시 추가, 바닥 스페큘러 끄기·스폿 크기 수정, 애니메이터 `AlwaysAnimate`로 소총을 두 손 사이에 맞춤.
- 자기 비판: 림 라이트가 뒷벽에 파란 얼룩, 측면 손잡이 장식이 어수선, 먼지 입자가 네모로 보임, 크레딧 링크가 제작자 열을 침범.
## 반복 3 (`iter3_*`)
- 수정: 손잡이 제거, 벽 워시 약화, 림 라이트 각도·거리 축소, 먼지 크기 축소, 크레딧 링크 열 줄바꿈+잘림.
- 남은 지적: 뒷벽 얼룩이 아직 옅게 보임, 벽 재질이 게임 콘크리트가 아니라 단색에 가까워 평평함, 로스터 인물 썸네일 미구현, 굵기는 Regular/Bold 2종, 헬멧·조끼는 게임 `LootMeshes` 모양(BACKLOG).
- 수치: PlayMode 캡처 3/3, EditMode 1327/1327. 로비 프레임 ms·드로우콜은 배치 모드에서 신뢰할 수 없어 미측정.

## 반복 4 (마스터 비평 전부 포함, `iter4_*`; 전: `iter3_*_after`)
- 점검/수정: ① 하단 바를 불투명 160px 막대 + 위 40px 페이드로, 한 줄 컨트롤(48px 마진·24px 간격) 아래에 안내 한 줄을 바 안에 둠(바 밖으로 삐져나오지 않음). ② 시작 버튼 360×72 주황 단색, 비활성도 불투명 면 + 흰 글자(대비 확보), 버튼 뒤로 투과 안 됨. ③ 먼지 입자·리벳(네모 점) 제거. ④ 벽에 가로 패널 줄눈 2줄, 조명을 점광원으로 바꿔 하드 콘 경계 제거(스포트가 벽에 대각선 경계를 만들었음). 필라스터는 검은 띠로 렌더돼 제거. 게임 `PaintedMetal`은 위장 무늬로 보여 벽에는 쓰지 않음. ⑤ 장비 모양 문제 목록·제안 `ui_GEAR_VISUAL_NOTES.md`. ⑥ 로스터 타일에 인물 썸네일(런타임 1회 렌더 15장, 비선택 60% 어둡게, 선택 2px 주황). ⑧ 5해상도 재캡처, 크레딧 링크는 열 안에서 줄여 맞춤.
- 남은 지적: 상단 좌우에 옅은 파란 얼룩(림 라이트), 벽 재질이 단색 위주(깊이는 조명에 의존), 헬멧·조끼 모양은 게임 원본, 굵기 2종(Regular/Bold)이라 위계는 크기·색.
- 수치: PlayMode 캡처 3/3, EditMode 1327/1327.

## 반복 5 (뒷벽·썸네일, `iter5_*`; 전: `iter5_lobby_squad_1920x1080_before.png` = iter4 결과)
- 파란 얼룩: 림 라이트가 벽 뒤(z=-2.4)에서 벽을 비추던 것 → 칸 안으로 이동. 키 라이트는 화면 오른쪽(x<0)에 있던 것을 왼쪽(+x)으로 바로잡음.
- 벽 재질: 게임 `WorldMaterials` 콘크리트를 시도했으나 **0.5 m 타일 박스에서 파셋(삼각 얼룩)이 생김**(파이프라인이 추가 광원을 버텍스 단위로 계산해 큰 면에선 대각선 경계, 타일로 쪼개면 체크무늬). 그래서 평평한 청회색 대신 **자체 제작 노이즈 텍스처**(Scenes/Lobby/LobbyWallNoise.png, 외부 에셋 아님)를 입힌 URP Lit + 가로 줄눈 2줄. 게임 PaintedMetal은 위장 무늬로 보여 제외.
- 로스터 썸네일: 런타임 렌더 대신 에디터 빌더가 로비 조명으로 15장을 `Resources/Ui/RosterThumbs/<ModelId>.png`(192×256)로 생성.
