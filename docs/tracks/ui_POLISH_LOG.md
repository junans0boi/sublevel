# UI 다듬기 반복 기록 (3D가 주인공, 캡처 → 자기 비판 → 수정 ≥3회)

반복마다 `docs/bible/img/ui/iter{N}_*.png`(전/후 같은 구도)를 남긴다. 체크리스트는 anti-slop · typography · spacing · colour-palette 스킬에서 가져왔다.

## 반복 0 (착수 전 위반 목록, 37f7fd3 캡처 기준)
- **구도**: 하단 콘솔이 화면 1/3, 카드·큰 LED·50칸 막대가 장면을 압도. 인물은 화면 높이의 약 24%. → 콘솔을 150 px 막대로, 카메라를 가깝게.
- **typography**: 글자 크기 15종(14~64), 굵기는 Bold 가짜 합성. → 실제 Bold 글꼴 추가(F-0002), 크기 스케일 16/18/20/28/32로 축소.
- **colour**: 강조색(파랑)이 탭·모드·시점·상태 버튼·LED·지도에 동시에 사용. → 강조는 선택된 모드 + 상태 버튼만, 시점·LED는 중립(흰색 12%).
- **spacing**: 시안 좌표가 8px 격자가 아님(예: 742, 868, 904). → 컴팩트 막대는 8의 배수.
- **anti-slop**: 장식 테두리·그라데이션 중복(패널마다 링+그라데이션+하이라이트), 레버·50칸 막대 같은 장식 위젯. → 레버·막대·타이머 숨김, 패널은 링 1px + 약한 그라데이션만.
- **motion**: 전환 없음. → UiFx(150/200/300ms ease-out/in, 투명도·8~12px 이동만, reduced motion 존중).

(이후 반복은 Unity 창이 열린 뒤 캡처하며 채운다.)
