# 결과 화면 데이터 자리 (UI ↔ 오염·팀 트랙, 껍데기 단계)

시안(`adopted.html` 결과)은 팀 순위표·오염 요약·탈출/열쇠/칩 요약·팀 결과를 보여 준다. 현재 게임 데이터(`ResultScreen`)에는 순위·킬·피해·생존 시간만 있어서 시안을 그대로 그리면 가짜 값이 들어간다. 그래서 병합 뒤에 아래 값이 채워지면 `MockScreen`(`Resources/Ui/Screens/result.json`, 이미 내보냄)으로 시안과 같은 화면을 그린다. 지금은 기존 `ResultScreen`을 그대로 쓴다.

필요한 값(오염·팀 트랙이 서버에서 확정해 클라이언트에 줄 것):
- 내 결과: 순위/전체 인원, 팀 순위/팀 수, 팀 킬, 내 킬, 준 피해, 생존 시간/전체 시간.
- 순위표(상위 N 팀): 팀 이름, 생존자 수/인원, 킬, 생존 시간, 승리 표시, 우리 팀 행 표시.
- 오염 요약: 오염 구역 노출 시간, 오염으로 받은 피해, 마지막 위치(지역명 + 안전 여부).
- 탈출·열쇠·칩: 열쇠 엘리베이터 사용 횟수, 최종 탈출 승강기 도달 여부, 칩 부활 받음/해 줌.
- 팀원별 줄: 이름, 킬, 피해, 생존 시간.
권장 형식: 한 개의 `MatchResultView` 구조체(순수 데이터, Core)로 서버가 채워 복제하고, UI는 읽기만 한다(ADR-246과 같은 방식).
