# 게임 장비 비주얼 문제 목록과 제안 (UI 트랙 → 다른 트랙에 넘길 메모, 제안만 함)

대상: `Scripts/Gameplay/LootMeshes.cs`의 코드 생성 모델을 캐릭터가 입는 `ArmorVisual`(헬멧·조끼)과 `BackpackVisual`(배낭). 외형 화면과 로비는 이 게임 비주얼을 그대로 쓴다(가짜 대체 없음).

## 현재 모양의 문제 (한 줄씩)
- **헬멧(`BuildHelmet`)**: 반지름 14 cm 반구 6단 + 챙 원판이라 머리 위에 얹은 파란 공으로 보인다. 목·귀 보호나 턱끈 형태가 없고, 모델 자체 헬멧이 있는 군복 3종(`HasHelmetMask`)에서는 겹친다.
- **조끼(`BuildVest`)**: 가로 38 cm 납작 상자 한 장을 가슴에 붙인 모양이라 몸통 곡면을 따르지 않고 어깨끈이 허공에 뜬다. 앞·뒤 상자 2개로 옆구리가 비어 있다.
- **배낭(`BuildBackpack`)**: 박스 + 반원통 뚜껑이라 등에 붙은 상자로 보이고 어깨끈이 캐릭터 어깨 곡면과 맞지 않는다. 단계(1~3)는 크기와 색 줄로만 구분된다.
- **공통**: 세 개 모두 단색 평면 재질(노이즈·모서리 둥글림 없음)이라 캐릭터의 텍스처 모델과 질감이 맞지 않는다.

## 제안 (구현하지 않음)
- 헬멧: 하이폴리 아닌 ~800 tri 전술 헬멧(ACH 형태: 챙·귀 쪽 곡선) 모델 1종 + 단계별 색/커버(CC0 후보는 Quaternius 군용 팩 계열·Kenney 모듈 소품 중 확인 필요, 라이선스는 ledger 선행).
- 조끼: 플레이트 캐리어 전/후면을 가슴·등 곡면에 맞춘 곡면 메시(~600 tri)와 어깨 연결부까지 한 메시로, 단계는 플레이트 수·파우치 개수로 구분.
- 배낭: 둥근 모서리의 배낭 메시(~600 tri) + 어깨끈이 어깨에 밀착, 단계는 크기·색·스트랩 수.
- 세 모델 모두 같은 3종 변형 색(황토·올리브·진녹)을 텍스처 없이 버텍스 컬러+노이즈 마스크로 유지하면 성능 변화가 없다.
