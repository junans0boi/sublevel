# PERF_BUDGET — 성능 예산 (잠정치 → M0에서 실측 후 확정)

기준 장비: MacBook Pro 13" M1(8GB 가정). 해상도 1080p 상당, URP.

| 항목 | 잠정 목표 | 최대 한도 | 측정 방법 |
|---|---|---|---|
| 프레임 | 60fps(16.6ms) | 최소 30fps(33ms) | 프레임타임 로그 평균/99퍼센타일 |
| 활성 구역 | 1개(이동 중 2개) | 2 | 씬 로드 로그 |
| 드로우콜/배치 | M0에서 확정 | | Frame Debugger/Profiler 로그 |
| 삼각형 | M0에서 확정 | | |
| 텍스처 | 1K~2K, KTX2 압축 | 4K 금지 | 임포트 검증 |
| 메모리 | M0에서 확정(8GB 기기 고려) | | |
| 로딩(구역 전환) | M0에서 확정 | | |
| 오디오 동시 발음 | 32 | 48 | 믹서 설정 |
| 프레임 중 GC 할당 | 0 목표 | 소량 | Profiler 로그 |
| 빌드 크기 | 목표 설정 M0 | | |

## 규칙
- 모든 PR/티켓에 측정값 첨부. 예산 초과 시 머지 금지, 최적화 티켓(`perf`) 생성.
- 측정 방법 자체가 헤드리스로 가능해야 함(M0-5).
- M0 이후 이 표의 "M0에서 확정"을 실제 수치로 교체하고 ADR 기록.

## 최적화 체크리스트
인스턴싱, SRP Batcher, LOD, 오클루전 컬링, 라이트맵, 구역 단위 로드/언로드, 풀링, 텍스처 해상도 제한, 섀도 거리 제한, 포스트프로세싱 최소.
